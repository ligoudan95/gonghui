## 第四批：配置去绝对路径（跨机可移植）

- 用户指令"项目内部相关配置尽量改相对路径，方便不同电脑调用"。全项目配置扫描结论：**唯一绝对路径 = `.zcode/config.json` 中 godot-mcp 的 `GODOT_PATH`**（本机编辑器 exe 路径）；其余本就干净——marketplace.json 用 `./gonghui-defense`、防线 hooks 用 `${CLAUDE_PLUGIN_ROOT}`、project.godot 全 `res://`。
- 方案依据：读 godot-mcp 源码确认探测链 = 裸命令 `godot` 优先（`execFile('godot',['--version'])` 验证，CreateProcess 自动补 .exe）→ 平台常见路径 → 失败。故**仓库配置删除 GODOT_PATH（env 置空），配置零绝对路径跨机通用**；各机保证 PATH 可解析 `godot.exe` 即可。
- 本机实施（已实测验证）：①编辑器同目录建 `godot.exe` **硬链接**（同卷零磁盘开销、免管理员）；②该目录**追加进用户 PATH**（.NET `[Environment]::SetEnvironmentVariable` 自带广播刷新，避开 setx 1024 字符截断坑）；③照服务端同款 `execFile('godot',['--version'])` 实测返回 `4.7.2.stable.official.ed1daf0bf` ✓。
- ⚠️ **另一台机器需同样两步**（其编辑器目录内建 godot.exe 硬链接 + 追加用户 PATH）；**编辑器升级换目录后两机都须重做**（硬链接与 PATH 均指旧目录）。ZCode 重启后新 PATH 与 MCP 配置同时生效。
