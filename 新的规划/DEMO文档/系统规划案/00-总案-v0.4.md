### 1.2 核心体验三支柱（设计支柱，非宣传卖点）

1. **当会长的养成感**：从破破烂烂的小公会做起，解锁建筑、招募冒险者、升级转职，眼看公会做大做强。
2. **掷骰抉择的代入感**：以麾下冒险者的属性参与事件检定与博弈，选择导向不同结局、发现隐藏秘密。
3. **小队战棋的策略感**：小地图回合制战旗，不重复职业混搭出策略深度。

三支柱的咬合点是：**冒险者是贯穿三层的唯一载体**——经营层是被养成的资产，冒险层是检定用的属性来源，战旗层是战斗单位。

### 1.3 目标玩家（推断）

核心：喜欢《废都物语》《暗黑地牢》式检定/事件驱动 RPG、且能接受战棋战斗的玩家；泛用户：二次元日式奇幻受众、模拟经营轻玩家。

## 二、核心玩法循环

> 本章描述**完整版目标形态**（系统设定层）；DEMO 实际包含范围见第八章，DEMO 外系统设定保留、实现暂缓。

### 2.1 大循环（三层串联）

```
【经营层·光辉城与公会】
  查看委托 → 选择委托 → 派遣小队（≤4人）
        ↓
【冒险层·野外地图（废都物语式）】
  格子探索 → 触发事件 → 属性检定（D20）/多分支抉择
  （检定与选择的结果影响接下来的战旗局）
        ↓
【战旗层·局内战斗】
  速度（敏捷换算）排序 → 移动/地形/技能（法力/精力双资源）
  → BUFF/DEBUFF 博弈 → 胜负（败=重伤休养，无永久死亡）
        ↓
【结算 → 反哺经营】
  佣金+素材+经验+声望（+压力/怪癖变化【DEMO 外·暂缓】）
  → 升设施 / 招募 / 锻造烹饪炼金 / 祷告解压
  → 攒声望 + 通过考核委托升旗 → 同档高奖励委托与新内容 → 循环
```

### 2.2 中循环（单次委托的完整流程，约 8 步）（推断展开）

1. 在冒险者协会（或城主大厅承接主线【DEMO 外·暂缓】）查看委托，注意剩余天数；
2. 依据委托需求（推荐属性/职业/区域）编成 4 人小队——混搭职业覆盖更多检定属性；
3. 出征进入野外地图，逐格探索揭示（消耗游戏内天数）；
4. 遭遇文本事件：选择分支 → 自动以队伍中对应属性最高者执行检定（可手动改派）；
5. 检定/分支结果改写战旗开局条件（如：潜行成功=敌方分散；大失败=被伏击）；
6. 进入战旗局，回合制战斗；
7. 结算：报酬、掉落、经验、声望；战败方为重伤休养+压力惩罚（无永久死亡，见 5.6）；
8. 返回公会：休整（宿舍/祷告室）、分经验（训练场）、消耗素材生产补给（锻造/厨房/炼金）。

### 2.3 小循环

- **战旗回合循环**：回合开始 → 按速度排序逐个单位行动（移动+行动）→ 敌方 AI 行动 → 回合结束结算持续性 BUFF/DEBUFF 与地格效果。
- **探索检定循环**：踩格/交互触发 → 弹出事件面板（选项标注所需属性与难度）→ 掷 D20 → 结果反馈（成功/失败/大成功/大失败各有文本与后果）。

### 2.4 时间推进系统（已定稿：日历制）

- 以**「天」**为最小单位；
- 推进日期的行为：出征探索（按区域/委托耗时）、设施生产完成、冒险者休息与恢复、协会招募池刷新（推断：具体天数数值由数值专项案确定）；
- 委托以剩余天数倒计时，到时刷新、消失或替换（原文设定，与日历制天然契合）；
- 主线章节与区域解锁以日期/公会等级为节奏闸门（推断；【DEMO 外·暂缓】）。

## 三、玩法模块一：冒险公会模拟经营

### 3.1 公会等级（旗帜）

- 由冒险者协会颁发；**硬规则**：公会内各设施等级 ≤ 公会等级（原文）；
- **提升途径（已定稿：声望+考核双轨）**：平时完成委托累积协会声望，声望达标后可承接「考核委托」，通过考核即升旗；
- **同档奖励（已定稿）**：委托等级与公会等级相同的委托，奖励显著高于普通委托；
- 公会等级作为内容解锁闸门：新区域、稀有委托、主线章节推进均与其挂钩（推断）；
- **DEMO 口径（推断建议）**：DEMO 内公会等级固定 1 档，声望仅作为结算展示数值；升旗/考核委托流程【DEMO 外·暂缓】。

### 3.2 六项设施

> 设施共六项；招募挂靠冒险者协会，不新增第七设施（已定稿）。
> **DEMO 口径（推断建议）**：DEMO 仅实现**宿舍 + 训练场**；其余四设施设定保留、实现暂缓。

| 设施 | 核心功能（原文） | 升级收益（原文） | 咬合系统（推断展开） | DEMO |
|---|---|---|---|---|
| 宿舍 | 决定能装多少冒险者 | 增加冒险者上限、提高休息效率 | 压力恢复、状态刷新、出征轮换深度 | 含（1-2 级） |
| 训练场 | 升级后选职业倾向、解锁技能；为未出战角色分享部分经验 | 提高技能解锁档位、提高经验分享效率 | 二转养成、板凳深度 | 含（1-2 级，第 1 档技能） |
| 锻造室 | 锻造武器装备；自制可定制属性但**无法获得最强装备** | 解锁新装备、提高词条装备出现概率 | 素材消耗；最强装备来源见 3.4 | 暂缓 |
| 厨房 | 制作食物 | 提高高品质食物概率、增强食物效果 | 出征携带补给 → 战旗/探索增益 | 暂缓 |
| 炼金室 | 酿造药水，增益兼有负面效果 | 提高药水效果、减少负面效果 | 战旗局内消耗品 | 暂缓 |
| 祷告室 | 降低冒险者压力、神术驱散怪癖 | 提高解压效果、降低花销 | 压力/怪癖系统（见 3.3） | 暂缓 |

### 3.3 冒险者管理

- **获取（已定稿：协会招募池）**：冒险者协会设招募池，按天定时刷新候选，花费用招募；关键 NPC 经剧情互动邀请入会（原文；【DEMO 外·暂缓】）；
- **DEMO 口径（推断建议）**：初始直接给一支固定小队（建议覆盖 4 个不同职业），招募池做简化版（少量候选刷新）或直接暂缓；
- **养成**：升级 → 训练场选职业倾向 → 解锁技能 → 二转（更极端也更强力，原文；二转【DEMO 外·暂缓】）；
- **状态系统（已定稿：中度后果；实现【DEMO 外·暂缓】）**：高压力 → 触发状态减益与**负面怪癖**；压力满 → 该冒险者一段时间**拒绝出征**（不毁档、不失控发作）；
- **轮换**：最多 4 人出战，板凳角色靠训练场经验分享成长（原文）。

### 3.4 经济与资源闭环（推断展开）

```
收入：委托佣金（主，同档委托显著更高）、素材/装备出售
支出：设施升级、招募、购买（菜市场的食材、矮人协会的装备、
      市井摊位的怪物素材、神秘商人的珍稀物件与赌箱）
生产：素材 → 锻造/厨房/炼金 → 装备/食物/药水 → 出征消耗
循环：委托奖励 → 投资生产与养成 → 打更高级委托
```

- **最强装备来源（已定稿）**：稀有委托 + 隐藏探索专属掉落；自制锻造「可定制但非最强」；神秘商人赌箱定位为趣味/幸运玩法，不承担最强装备产出；
- （推断）货币之外至少三类素材流：食材（菜市场/厨房）、矿物（矿洞/锻造）、怪物素材（掉落/市井摊位/多用途）。

## 四、玩法模块二：属性鉴定类 CRPG 多分支（冒险层）

### 4.1 探索表现（参考废都物语）（推断展开）

- 野外地图以**格子逐步揭示**呈现（战争迷雾），小队图标在格间移动；
- 每次移动/交互可能触发：文本事件、遭遇（进入战旗）、宝箱、可交互点、**暗门/捷径（感知检定发现）**；
- 事件以**文本面板 + 选项**呈现，选项旁标注所需属性与难度，选择后掷骰检定；
- 「四通八达」的矿洞做成多层网状地图，检定成功可打通捷径改变路线。

### 4.2 属性检定机制（已定稿）

- 七项一级属性**全部**有对应检定事件（原文）；
- **骰制：可见骰 D20**——检定值 = 属性调整值 + D20 结果，对比事件难度等级；骰出 20 为大成功、骰出 1 为大失败，各触发专属文本与后果；
- **执行者：自动取最高**——自动选队伍中对应属性最高的冒险者执行检定，允许手动改派；
- 检定/分支结果改写战旗开局条件（原文：影响局内战斗成败）；
- **设计原则建议（推断）**：检定失败不造成死路——失败导向另一条分支，配合大成功/大失败制造戏剧性。

### 4.3 七属性双用途对照表（映射骨架已定稿，细则为推断建议）

| 属性 | 冒险层检定场景（推断示例） | 战旗层映射（推断建议） |
|---|---|---|
| 力量 | 破门/搬石/威吓 | 近战伤害、击退效果 |
| 敏捷 | 潜行/攀岩/偷窃/躲避机关 | 行动顺序（速度）、闪避率、移动力 |
| 体质 | 长途跋涉/耐毒/忍耐 | 生命值、异常状态抗性 |
| 智力 | 解谜/古语解读/法术知识 | 法力值、法术伤害、法术穿甲 |
| 感知 | 侦察暗门/追踪/察觉伏击 | 视野、命中、先手优势 |
| 魅力 | 交涉/砍价/说服/情报 | **奇术强度（奇术师 DEBUFF 效果）**、士气类 BUFF、商店价格、NPC 事件（推断） |
| 幸运 | 赌博/寻宝/意外惊喜 | 暴击率、掉落、D20 大成功倾向加成（推断） |

### 4.4 分支结构、隐藏内容与多结局

- （推断）事件分支的四种出口：结算奖励差异 / 进入不同战旗开局 / 解锁隐藏区域或隐藏秘密 / 影响结局与 NPC 关系；
- **多结局框架（方向已定稿：混合反转主线，结构为推断）**：整体结局取决于明线（怪物异变）与暗线（人为阴谋）两线的调查深度与关键抉择——主线与多结局均为「DEMO 外·暂缓」，设定保留见 6.3。

## 五、玩法模块三：局内战旗

### 5.1 基本框架

- 简化版战棋：**相对较小的地图**内回合制战斗（建议规模 8×8 ~ 12×12 格）（推断）；
- 我方最多 4 名角色（原文）；
- **职业混搭的鼓励方式（已定稿：自然混搭，用户原意）**：不设连携机制、不设数值加成——不同职业的属性倾向覆盖不同检定属性，混搭队伍可以最大程度发挥属性优势、在随机事件中取得先机；以「职业属性倾向覆盖表」（见 5.3）强化自然引导；
- 行动顺序由速度排序决定，**速度 = 敏捷属性换算，不另立属性**（已定稿）；
- 移动力 = 可移动格数；障碍地格阻挡前进；状态地格提供不同增益（原文）。

### 5.2 地格与回合细则（推断展开）

- 状态地格示例方向：草丛（闪避+）、高地（伤害+）、毒沼（持续伤害）、祝福祭坛（回合 BUFF）；
- 回合结构建议：单位行动 = 移动 + 行动（技能/攻击/使用道具），回合末结算持续性效果与地格效果；
- 敌方为 AI 行动（规模与 AI 深度留待后续专项案）。

### 5.3 六职业定位、属性倾向与二转方向

> 第六职业：**奇术师**（已定稿：主属性=魅力、副属性=感知、法系职业、负面状态控制系；此前「奇书师」为笔误，已更正）。

**职业属性倾向覆盖表（已定稿方向：自然混搭引导；具体倾向数值为推断建议）**：

| 职业 | 主属性倾向 | 覆盖的检定属性 | 定位 | 二转方向（推断占位；【DEMO 外·暂缓】） |
|---|---|---|---|---|
| 战士 | 力量/体质 | 力量、体质 | 前排坦克/近战输出（推断） | 防御极端型 / 输出极端型 |
| 盗贼 | 敏捷/幸运 | 敏捷、幸运 | 高机动/暴击/检定多面手（推断） | 爆发刺杀型 / 陷阱控制型 |
| 法师 | 智力 | 智力 | AOE 法术输出/硬控制（推断） | 轰炸极端型 / 控制极端型 |
| 牧师 | 感知/魅力 | 感知、魅力 | 治疗/驱散/亡灵克制（推断） | 治疗强化型 / 惩戒输出型 |
| 游侠 | 敏捷/感知 | 敏捷、感知 | 远程物理/地形利用（推断） | 远程狙杀型 / 兽伴召唤型 |
| **奇术师** | **魅力（主）/感知（副）**（已定稿） | **魅力、感知** | **控制系：以奇术施加负面状态（DEBUFF），削弱并绞杀敌人**（已定稿方向）；表现形态：诅咒（持续削弱/伤害）、幻术（迷惑：命中/视野类削弱）、蛊惑（行动限制/操控类）（推断细化） | 诅咒极端型 / 蛊惑极端型（推断占位） |

**与法师的定位区分（按新属性重写，推断）**：

| 维度 | 法师 | 奇术师 |
|---|---|---|
| 属性 | 智力系 | 魅力系（副：感知） |
| 战斗节奏 | 瞬时爆发：AOE 伤害 + 硬控制（定身/冰冻类），当场改变战局 | 回合累积：DEBUFF 叠加（诅咒/幻术/蛊惑），随回合数逐步绞杀 |
| 战术定位 | 解决「这回合怎么打出优势」 | 投资后续回合，解决「这场仗怎么越打越顺」 |
| 资源 | 法力值 | 法力值（同为法系，已定稿） |
| 检定侧写（推断） | 古语解读、法术原理、解谜 | 蛊惑交涉、看破人心、秘仪知识 |

**七属性覆盖核验（奇术师定稿后）**：力量（战士）、敏捷（盗贼/游侠）、体质（战士）、智力（法师）、感知（牧师/游侠/奇术师）、魅力（牧师/奇术师）、幸运（盗贼）——**无覆盖缺口**。分布变化（推断）：体质回落至战士独占、智力回落至法师独占；感知升至三职业覆盖；魅力升至两职业；幸运仍为盗贼独占。4 人小队最多覆盖 4 个职业的倾向属性，永远存在检定短板——编队在「委托的检定需求」与「战旗战斗强度」之间取舍，是本作编队策略的核心趣味。

### 5.4 一级属性 → 二级属性映射（骨架已定稿）

- 二级属性清单（原文 12 项）：生命值、法力值、精力值、闪避率、物理穿甲、法术穿甲、物理抗性、法术抗性、物理护甲、法术护甲、暴击率、暴击伤害倍率；
- **伤害公式（已定稿：属性直接计算）**：伤害 = 一级属性 + 武器 + 技能系数直接计算；二级属性仅做修正，**不增设隐藏攻防属性**；
- **速度（已定稿）**：由敏捷换算，决定行动顺序；
- **双资源体系（已定稿）**：**法系职业（法师/牧师/奇术师）主要消耗法力值，物理职业（战士/盗贼/游侠）主要消耗精力值**；DEMO 内建议以战后自动恢复/回公会休息代替（推断建议）；
- 映射细则为后续数值专项案内容，本案只锁骨架。

### 5.5 BUFF/DEBUFF 框架

- 正面与负面效果并存（原文）；
- 奇术师入队后，DEBUFF 体系从「辅助手段」升级为「可围绕构建的核心玩法」（推断：DEBUFF 类型池与叠加规则是战旗专项案的重点设计项）；
- （推断）来源：技能、状态地格、药水/食物、事件检定结果带入。

### 5.6 战斗胜负与后果（已定稿）

- **胜利**：进入结算（报酬/掉落/经验/声望）；
- **战败 = 委托失败 + 冒险者重伤休养 + 压力惩罚，无永久死亡**：重伤休养若干天（推断），期间无法出征；
- **「永久死亡」仅作高难开关预留**（【DEMO 外·暂缓】）：默认关闭。

## 八、DEMO 范围界定（体量定位已定稿；范围为推断建议，供审核）

### 8.1 DEMO 目标（推断建议）

验证一件事：**「单次委托完整循环」是否好玩**——接委托 → 派队 → 探索检定 → 战旗 → 结算 → 反哺 → 接更高难度委托。同时验证两个单点：战旗手感、D20 检定趣味。

### 8.2 DEMO 包含系统清单（推断建议）

| 层 | 系统 | DEMO 内规格 |
|---|---|---|
| 经营 | 日历时间 | 以天推进、委托剩余天数倒计时 |
| 经营 | 委托板（冒险者协会） | 普通委托 4-6 个模板，等级 1 档，到期刷新 |
| 经营 | 宿舍 | 1-2 级：冒险者上限、休息恢复 |
| 经营 | 训练场 | 1-2 级：升级选职业倾向、解锁第 1 档技能、板凳经验分享 |
| 经营 | 招募 | 简化：初始固定小队（建议 4 人覆盖 4 个不同职业）+ 少量候选刷新 |
| 冒险 | 野外地图 1 张 | 村子（中继）+ 矿洞一层；格子揭示、事件点、宝箱、暗门 1 处（感知检定演示） |
| 冒险 | 事件检定 | D20 可见骰、自动取最高可改派、大成功/大失败；事件链 2-3 条 × 3-5 分支 |
| 战旗 | 战斗 | 小图 2-3 张；六职业各 1-2 技能（无二转）；速度/移动力/障碍/状态地格 2-3 种；BUFF/DEBUFF 基础池（奇术师 DEBUFF 演示） |
| 战旗 | 双资源 | 法系法力值 / 物理精力值 |
| 结算 | 反哺闭环 | 佣金 → 宿舍/训练场升级 + 招募；经验 → 升级选倾向；战败重伤休养（无永久死亡） |

### 8.3 DEMO 不包含（暂缓清单）

- **剧情全套**：主线、暗线、多结局、路人台词体系、城主大厅、关键 NPC 入会；
- **四设施**：锻造室、厨房、炼金室、祷告室（含生产链与消耗品系统）；
- **压力与怪癖系统**；**二转职业**；**稀有/考核委托与多档公会等级**（DEMO 固定 1 档）；
- **最强装备**；**大森林区域、光辉城其余五场所**（DEMO 内光辉城仅冒险者协会可用）；
- **永久死亡高难开关**。

### 8.4 最小可玩组合（推断建议）

初始 4 名冒险者（覆盖 4 个职业）→ 协会接 1 个委托 → 矿洞一层探索（2-3 次事件检定 + 1 场战旗）→ 结算 → 回公会消费（升级设施/招募/解锁技能）→ 接下一个委托。目标体验时长：单循环 20-40 分钟，DEMO 总计 2-4 小时（占位数值，供排量参考）。

### 8.5 构建顺序建议（推断）

① 战旗手感原型（1 图、4 人、6 职业各 1 技能、双资源、基础地格）→ ② 检定事件原型（1 条事件链、D20、自动取最高）→ ③ 组装 DEMO 循环（补经营最小集 + 结算反哺）→ ④ 双端触控 UI 验证贯穿全程（已定稿：横屏、触控优先、双端同版）。

## 十、内容配置化需求（策划视角，供后续架构参考）

DEMO 阶段即须落实「表驱动」，且**数据结构按完整版标准设计（范围可小、结构不能歪）**：

- **须以可配置数据而非硬编码存在的内容**：委托（时限/等级/奖励/关联事件链）、事件与分支文案（节点、检定属性与难度、结局）、职业与技能数值、属性映射表、地图与地格、设施升级收益表、（完整版）商品/食谱/药水配方、锻造词条池；
- **理由**：① DEMO 内数值必然反复调整，表驱动使调参不依赖程序改动；② 数据结构按完整版标准建立，验证通过后可直接扩量；③ 后续迭代复用同一套生产管线；
- **原则**：内容与逻辑分离——调整内容不改程序，扩充内容不动框架。
