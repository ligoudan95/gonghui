# 案 7《地图探索系统规划案》

## 1. 系统定位与目标

- **定位**：冒险层的空间载体——格子探索（参考废都物语）承载事件触发（案 8）、战斗遭遇（案 9）、宝箱与暗门；
- **服务的核心体验**：掷骰抉择的代入感（未知格子的期待感与探索决策）。

## 2. 机制细则

### 2.1 基础规则

- **格子地图**：正交网格（推断），小队以单一图标在格间移动（原文表现形式）；
- **战争迷雾（推断）**：未到达区域不可见；进入格子揭示周围 1 格范围（占位）；**感知属性扩大揭示半径**（推断：高感知队员在队即生效）；
- **移动不单独耗天**：出征整体耗时按案 2 行为耗时表计；移动仅受格间邻接与障碍限制。

### 2.2 交互点类型与触发规则（推断：固定布置为主、随机遭遇为辅）

| 类型 | 触发方式 | 效果 |
|---|---|---|
| 事件点 | 踩格/交互固定布置 | 进入事件链（案 8），单次消耗 |
| 战斗遭遇点 | 固定布置（必然）+ 踩格随机（概率） | 进入战旗局（案 9） |
| 宝箱 | 交互触发 | 直接奖励；可配置陷阱检定（推断） |
| 暗门/捷径 | 感知检定发现（案 8） | 揭示隐藏格子/开启通路，改变路线 |
| 出口/层间节点 | 交互触发 | 层间转移（完整版）/完成委托目标 |

- 设计原则（推断）：固定布置保证叙事与难度曲线可控；随机遭遇提供波动——概率与区域危险度挂钩（DEMO 低频）。

### 2.3 暗门与捷径（原文+细化）

- 靠近暗门区域时触发**感知检定**（案 8 执行，自动取最高可改派）：成功→揭示暗门与捷径通路；失败→不可见，但「失败也推进」（可绕行或后续再探，不死锁）；
- 打通捷径改变路线：跳过危险区直连深处/回程近路——「四通八达」矿洞的核心玩法（完整版）。

### 2.4 区域结构（完整版方向，推断）

- **矿洞**：多层节点图 + 层内网格图；检定打通跨层捷径形成网状路线；
- **村子**：安全中继（无战斗、少量人情事件）；**大森林**：高自由度大图（暂缓，案 12）。

### 2.5 出征与撤退规则（推断建议）

- 撤退：探索中可随时撤退回城，**委托不判失败**（时限继续倒计时），同一次委托内再进入该地图**进度保留**（迷雾、交互点状态保留）；
- 委托结束后地图实例销毁，下次同模板委托重新生成（宝箱等一次性内容重置）。

### 2.6 与战旗的衔接

- 遭遇点触发 → 载入战旗局（携带案 8 开局参数包，若有）→ 胜利返回探索层原位继续；战败→按案 9 结算回城；
- 一张探索图内可含多个战斗触发点（DEMO 建议 1-2 个）。

## 3. 数据与配置需求

| 表 | 字段建议 |
|---|---|
| 地图定义 | 地图 id、所属区域 id（案 12）、尺寸、格子类型矩阵、交互点布置列表（类型/位置/关联配置/单次性标记）、危险度、基础出征耗时 |
| 格子类型 | 类型 id、可通行性、表现资源 |
| 遭遇权重 | 区域危险度→随机遭遇概率、敌方配置池引用 |
| 迷雾配置 | 基础揭示半径、感知加成规则 |

## 4. 与其他系统的接口

- **输入**：案 5（感知揭示范围）、案 6（委托指定目标地图）、案 8（暗门检定结果）、案 9（战斗胜负返回）；
- **输出**：事件/遭遇触发、耗时申报→案 2、宝箱奖励→案 4/5；
- **依赖**：案 2/5/8/9；**被依赖**：案 6（委托目标）、案 12（区域内容定义）。

## 5. DEMO 口径

- **做**：1 张探索图=村子（安全中继、无战斗、1-2 个轻事件）+ 矿洞一层（15×15 以内占位）；固定布置为主（事件点 2-3、必然遭遇 1、宝箱 2-3、暗门 1 处演示）+ 低频随机遭遇；感知揭示加成；撤退与进度保留；出征固定 1 天（占位）；
- **不做（暂缓）**：多层矿洞节点图、跨层捷径、大森林、陷阱宝箱检定（可后补）、区域危险度分档。

## 6. 风险与待专项细化项

- **风险**：① 探索图+战旗图双制作成本（DEMO 已按最小规格控制）；② 随机遭遇频率的挫败感；③ 迷雾揭示半径的探索感/节奏平衡；
- **待专项细化**：数值专项案（揭示半径/遭遇概率/耗时）；案 12（区域美术与场景内容）；事件专项案（探索途中事件文案）。
