# 17-数值专项案（v1.0·已定稿框架）

> **标注体系**：沿用系统案体系。本案全部推荐数值 = 【占位·试玩校准】（DEMO 表驱动落地后试玩回调，不构成定稿）；方向性决策已全部经用户拍板（见文末拍板记录）。凡与已定稿机制冲突的数值一律不设（伤害公式 #17 乘数式、两段判定 #5、减免轨、幸运降线/兜底 #15、重伤仅战败 #6 等，本案只填参数不改动机制）。
> **版本**：v1.0（2026-09-21 用户审核定稿：6 项方向性决策均经用户在线拍板，按推荐项落定；全部数值仍为【占位·试玩校准】性质，DEMO 试玩后回调）

## 一、定位与范围

- **定位**：全部 18 份系统案数值占位的唯一收口案——一级/二级属性值域与换算、D20 检定参数、伤害与战斗公式参数、生存恢复、成长曲线、经济收支、敌人配置、战棋基准、时间与压力参数；交付后各案「数值案定」标注可回填。
- **范围**：DEMO 必配数值为主（11 域参数表 + DEMO 最小数值集）；完整版存档参数（压力、按天恢复、稀有度曲线等）一次给齐参数位、标注【存档】。
- **不做**：事件文案数值美感、剧情阈值（归剧情专项案）、战棋分层 AI 参数（归战棋专项案）。

## 二、数值体系总纲（设计原则）

1. **玩家可感知的整数**：所有面板/跳字展示整数（内部计算保留小数，展示四舍五入）
2. **小数值域**：一级属性初始 6-17、成长软上限 25（DEMO 实际最高约 21）；伤害/资源两位数、货币三位数——玩家心算可及
3. **10 为基准线**：属性 10 = 无修正（调整值 0），高有奖励低有惩罚，双向可读
4. **对称换算**：所有二级属性 = 基准值 + 属性调整值 × 系数，一套心智模型走全游戏
5. **不防刷**（案 7 #12 已定稿）：收益节奏靠本案例收支平衡控制
6. **验算先行**：所有战斗域数值必须通过「3-5 回合战斗目标」推演（见 §3.4/§3.8 验算）

| 二级属性 | 换算式 | 备注 |
|---|---|---|
| 生命值 | 20 + 体质×5 + 职业生命系数×(等级−1) | 职业系数：战士 8 / 牧师·游侠 5 / 盗贼·奇术师 4 / 法师 3 |
| 法力值 | 10 + 主属性×3（法师=智力、牧师=感知、奇术师=魅力） | 【已定稿·用户拍板】资源池统一从职业主属性换算（六职业）；骨架默认（智力/体质）作兜底 |
| 精力值 | 10 + 主属性×3（战士=力量、盗贼=敏捷、游侠=敏捷） | 同上；解决盗贼（体质低）精力池过小问题 |
| 闪避率 | 5% + 敏捷调整值×2% | |
| 命中率 | 80% + 感知调整值×2% + 技能命中修正 | #4 |
| 异常状态抗性 | 5% + 体质调整值×3% | #5 |
| 速度 | = 敏捷原始值（直接排序，同速打破平已定稿） | 速度类 BUFF 改敏捷 ±N |
| 物理穿甲 | 力量调整值×1（点） | 点数直接抵消护甲 |
| 法术穿甲 | 智力调整值×1（点）；奇术师特例=魅力调整值×1 | #17 奇术师魅力主导 |
| 物理抗性 | 体质调整值×2% + 装备 | |
| 法术抗性 | 感知调整值×2% + 装备 | 精神抗性口径 |
| 物理/法术护甲 | 装备护甲值（主导）+ 对应换算源调整值×1 | 物理←体质、法术←感知；钳制 ≥0 |

| 暴击伤害倍率 | 150% 基础 + 技能/装备词条加成 | 属性微调留完整版【存档】 |

- 池量级示例（1 级）：战士生命 20+14×5=90、法师 60；法师法力 58、战士精力 58。
- 二级属性为派生值实时计算（案 5 已定策划口径），本表即派生公式参数。

### 3.4 伤害与战斗域（案 9/10 公式参数收口）
