# 案 9《战旗战斗系统规划案》

## 1. 系统定位与目标

- **定位**：三层玩法的战斗验证与压力释放点——简化版战棋（原文：相对较小的地图、回合制）；接收检定开局改写，输出战斗结算。
- **服务的核心体验**：小队战棋的策略感（每场可复盘的棋局）。

## 2. 机制细则

### 2.1 战场与回合结构（已定稿方向展开，推断细则）

- **战场**：正交网格小图，规模 8×8 ~ 12×12（推断占位）；地格三分类：普通 / 障碍（原文）/ 状态（原文）；
- **回合流程**：
```
战斗开始：应用开局参数包（案8）→ 按速度生成行动序列
回合开始：按当前速度重排序列（占位建议，使速度类 BUFF 有意义）
回合内：按序列逐单位行动（移动 + 行动，各一次，顺序任意）
回合结束：结算持续状态（案11）与地格效果 → 判定胜负 → 下一回合
```
- **胜利条件（DEMO：歼灭）**：敌方全灭；完整版扩展目标型胜利（守点/护送/撤退，存档）；
- **战败**：我方全灭 → 已定稿结算（委托失败+重伤休养+压力惩罚【压力暂缓】，无永久死亡；「永久死亡」仅高难开关预留）。

### 2.2 速度与移动力

- **速度（已定稿）**：敏捷换算决定行动顺序；**同速打破平（推断）**：我方优先→仍同则按队伍槽位/敌方按配置序；
- **移动力**：基础值+职业修正+敏捷微调（推断，数值案定）；**穿越规则（推断）**：友方可穿越不可停留，敌方阻断；移动路径预览（案 15）。

### 2.3 状态地格（推断示例，效果经案 11 施加）

| 地格 | 触发时机 | 效果 |
|---|---|---|
| 草丛 | 站上生效、离开失效 | 闪避+ |
| 高地 | 站上生效 | 伤害+ |
| 毒沼 | 站上期间每回合末 | 持续伤害 |
| 祝福祭坛 | 站上生效 | 指定 BUFF |

结算时机统一挂回合末流程（案 11 提供「回合末结算清单」）。

### 2.4 行动内容（推断）

- **移动**：消耗移动力；**攻击/技能**：消耗行动次数+资源（案 5 双资源；技能归案 10）；**使用道具**（暂缓）；**待机**；
- 命中判定框架（推断）：基础命中与目标闪避率对抗（公式留数值专项案）；伤害=一级属性+武器+技能系数（已定稿）经护甲/抗性/穿甲修正（物理/法术分轨）；远程需视线（障碍阻断射线，推断）。

### 2.5 敌方 AI（DEMO 简化版，推断建议）

- 优先级制决策：可击杀目标（估算伤害≥目标剩余生命）＞ 当前攻击目标持续追击 ＞ 血量最低/距离最近 ＞ 默认最近我方；
- 不做包抄、集火切换、地形利用（完整版分层 AI 另案，DEMO 明确「够蠢但有威胁」）；
- 敌方单位定义复用属性/技能字段结构（独立敌人定义表，无养成字段）。

### 2.6 开局参数包接收（案 8 接口）

战斗载入时按参数包应用六维度（先手权/敌方分布/初始地形/初始状态/构成微调/我方站位）；未填维度用战斗配置默认值。

### 2.7 战斗结算

- 胜利：奖励发放（案 4/5/6）+ 返回探索层（案 7）；
- 战败：重伤休养回写（案 5）+ 委托失败（案 6）+ 回城；
- 战斗内损耗保留至探索层，按案 5 恢复规则处理。

## 3. 数据与配置需求

| 表 | 字段建议 |
|---|---|
| 战旗地图 | 地图 id、尺寸、地格矩阵、我方出生区、敌方默认布置、预设状态地格位 |
| 敌人定义 | 敌人 id、名称、职业定位标签、七属性基础值、资源、技能列表引用、移动力、掉落引用、立绘/模型资源 |
| 敌方队伍配置 | 配置 id、敌人组合、数量、精英标记 |
| AI 配置 | 决策优先级参数（DEMO 固定） |
| 开局参数包 | 字段=案 8 之 2.5 清单（六维度+默认值标记） |
| 战斗规则配置 | 同速规则、命中/伤害公式参数位 |

## 4. 与其他系统的接口

- **输入**：案 7（遭遇触发）、案 8（开局参数包）、案 5（我方单位数据包）、案 10（技能调用）、案 11（状态施加与结算）；
- **输出**：战斗结算→案 5/4/6/7；
- **依赖**：案 5/8/10/11；**被依赖**：案 7（遭遇）、案 6（委托战斗环节）。

## 5. DEMO 口径

- **做**：战旗图 2-3 张（8×8~10×10 占位，歼灭胜利）、简化 AI、六职业可编入出战、基础地格 2-3 种、开局参数包接收（演示先手权+敌方分布两维度）、速度排序与同速规则、移动路径预览、回合末结算挂接案 11；
- **不做（暂缓）**：目标型胜利条件、道具使用、分层 AI、永久死亡开关、视线精细化（DEMO 先做简单遮挡判断或全通视，二选一试玩定）。

## 6. 风险与待专项细化项

- **风险**：① 战棋手感（DEMO 核心验证点之一）；② AI 强度失当；③ 占位数值的反复调整（DEMO 需先拍一套占位数值试玩）；④ 4vN 的敌方数量与回合膨胀；
- **待专项细化**：数值专项案（命中/伤害/护甲公式、移动力基准）；案 10/11（技能与状态定义）；案 15（战棋操作 UI 与触控精度）。
