# 案 5《冒险者系统规划案》

## 1. 系统定位与目标

- **定位**：冒险者是三层玩法的唯一载体——本案定义冒险者实体（属性/成长/状态/获取），为战旗（案 9/10/11）、检定（案 8）、公会养成（案 3）提供统一数据源；
- **服务的核心体验**：三支柱的咬合点本体——同一批人在经营层是资产、冒险层是检定属性源、战旗层是战斗单位。

## 2. 机制细则

### 2.1 实体属性体系

- **七项一级属性**（原文）：力量、敏捷、体质、智力、感知、魅力、幸运——全部有对应检定事件（已定稿）；
- **十二项二级属性**（原文）：生命值、法力值、精力值、闪避率、物理穿甲、法术穿甲、物理抗性、法术抗性、物理护甲、法术护甲、暴击率、暴击伤害倍率；
- **伤害公式（已定稿）**：伤害 = 一级属性 + 武器 + 技能系数，二级属性仅做修正，不增设隐藏攻防；
- **速度（已定稿）**：由敏捷换算，决定战旗行动顺序；
- **双资源（已定稿）**：法系职业（法师/牧师/奇术师）主要消耗**法力值**，物理职业（战士/盗贼/游侠）主要消耗**精力值**。

### 2.2 一级→二级属性映射骨架（推断建议，系数留数值专项案）

| 二级属性 | 主导来源（推断） | 附注 |
|---|---|---|
| 生命值 | 体质 + 职业系数 + 等级 | 坦克职业系数更高 |
| 法力值 | 智力 + 职业系数 | 法系（法师/牧师/奇术师） |
| 精力值 | 体质 + 职业系数 | 物理系（战士/盗贼/游侠） |
| 闪避率 | 敏捷 | |
| 物理穿甲 | 力量 | |
| 法术穿甲 | 智力 | 奇术师特例：奇术效果强度由**魅力**主导（奇术强度），穿透类修正细则归数值专项案 |
| 物理抗性 | 体质 + 装备 | |
| 法术抗性 | 感知 + 装备 | 精神抗性口径（推断） |
| 物理/法术护甲 | 装备主导 + 属性微调 | 装备归案 4 |
| 暴击率 | 幸运（主导）+ 敏捷（微调） | 与幸运的横跨定位一致 |
| 暴击伤害倍率 | 技能/装备主导 + 力量或智力 | |

二级属性为**派生值**：由一级属性+装备+BUFF 实时计算（推断：不作为独立成长项存储，避免双轨维护——供架构师参考的策划口径）。

### 2.3 等级与成长

- **经验获取**（原文+推断）：出战冒险者获得主要经验（分配比例留数值案）；未出战角色经**训练场分享**获得一部分经验（分享效率随设施等级提升，案 3）；
- **升级**（推断骨架）：经验达阈值升级；升级获得基础全属性小幅成长 + **职业倾向加成成长**；经验曲线与成长数值留数值专项案；
- **职业倾向选择**（原文：训练场功能）：冒险者升级后在训练场选择职业倾向（发展路线）——倾向决定：① 属性成长侧重（主属性额外成长）；② 该档位可解锁的技能池分支。倾向选项清单归案 10 定义，本案只定机制挂接点；
- **技能解锁**（原文+推断）：技能按**档位**解锁，档位上限由训练场设施等级决定（案 3）；DEMO 开放第 1 档；
- **等级上限**：DEMO 设上限（占位建议 5-10 级，数值案定），完整版随公会等级扩展（推断）。

### 2.4 招募

- **协会招募池（已定稿）**：冒险者协会设招募池，**按天定时刷新**候选，花费货币招募；不新增第七设施；
- **招募池细则（推断建议）**：池容量 3-5 人；每日日结算刷新（案 2 第 5 步）；候选随机生成（职业、七属性基础值在职业倾向范围内浮动；完整版可附随机怪癖——挂案 14 暂缓）；刷新为整池替换，是否设「付费保留候选」留完整版；招募花费随候选质量浮动（数值案定）；
- **关键 NPC 入会（原文，DEMO 外·暂缓）**：剧情互动邀请强大 NPC 入会——入会 NPC 与普通冒险者同实体结构、可设定独有立绘与技能（存档，剧情触发归案 13，NPC 场景归属归案 12）；
- **DEMO 口径**：初始固定 4 人小队（推断建议：战士/盗贼/法师/牧师——覆盖力量/敏捷/智力/感知，经典构成易上手）；简化招募池（容量小、候选偏向玩家未持有的职业，确保六职业在 DEMO 内均可体验）；
- **解雇/退役（推断）**：可解雇腾出宿舍名额（完整版；DEMO 留字段位）。

### 2.5 状态系统

- **健康**：正常可出征；
- **重伤休养（已定稿方向+推断细化）**：战旗战败→委托失败+重伤休养若干天（天数随重伤程度，数值案定）+压力惩罚（压力部分暂缓）；休养期间无法出征、不参与检定；休养按日结算推进（案 2 第 3 步），宿舍休息效率加成可缩短休养（加成细则与案 3 对齐）；
- **战后损耗恢复（推断）**：非重伤的生命/法力/精力损耗，回城后自动进入恢复状态，按天恢复（宿舍效率加成）；DEMO 简化为回城当日全额恢复（占位建议——是否保留「按天恢复」的张力留 DEMO 试玩验证）；
- **压力/怪癖（案 14，DEMO 外·暂缓）**：本案仅保留实体字段位（stress 值、quirk 列表）与状态互斥规则占位。

### 2.6 轮换与编队

- 出征小队最多 4 人（原文）；无编队数量下限（1-4 人皆可出征，推断）；
- 编队入口：委托派遣界面（案 6）与公会界面均可调整默认小队（推断，UI 归案 15）；
- 板凳深度靠训练场经验分享维持（原文），与重伤休养共同推动多队轮换。

### 2.7 二转框架（DEMO 外·暂缓，存档）

原文：存在二转职业，在旧职业基础上强化对应发展方向，更极端但也更强力。结构：6 职业 × 2 方向 = 12 个二转（案 10 存档命名占位）。触发条件（推断占位）：等级阈值 + 训练场档位（完整版另议）。

## 3. 数据与配置需求（字段级草案）

| 表 | 字段建议 |
|---|---|
| 冒险者实例 | id、姓名、立绘/头像资源引用、职业 id、等级、经验、七一级属性基础值、当前生命/法力/精力、状态（健康/休养中/恢复中）、休养剩余天数、已选职业倾向、已解锁技能列表（技能 id+档位）、装备槽（字段位，案 4）、压力值与怪癖列表（字段位，案 14）、来源标记（初始/招募池/NPC）、招募花费 |
| 职业定义表 | 职业 id、名称、属性倾向（主/副）、资源类型（法力/精力）、战场定位描述、倾向成长修正、二转分支引用（暂缓）、职业图标资源 |
| 成长配置表 | 升级经验曲线（数值案）、每级基础成长值、倾向加成成长值（数值案）、等级上限（DEMO/完整版分列） |
| 招募配置表 | 池容量、刷新周期（对接案 2）、候选生成权重（职业/属性浮动范围）、花费基准（数值案）、保留候选规则（完整版） |
| 恢复配置表 | 每日恢复比例、宿舍效率加成系数（对接案 3，数值案）、重伤休养天数表（数值案） |

## 4. 与其他系统的接口

- **输入**：委托结算的经验/货币（案 6）、训练场档位与分享率（案 3）、日历的恢复/刷新/休养结算（案 2）、战旗结算的重伤与损耗（案 9）、检定的属性读取请求（案 8）、装备加成（案 4）、压力怪癖写入（案 14，暂缓）；
- **输出**：可出征单位池（编队界面）、检定属性值响应（自动取最高需可查询全队属性，案 8）、战旗单位数据包（属性/技能/资源/装备修正，案 9/10/11）、宿舍占用人数（案 3）；
- **依赖**：案 2（时间结算）、案 3（设施加成）、案 6（经验来源）、案 10（倾向与技能池定义）；
- **被依赖**：案 8（检定）、案 9/10/11（战旗）、案 6（派遣）、案 13/12（NPC 入会，暂缓）、案 14（状态挂接，暂缓）。

## 5. DEMO 口径

- **做**：冒险者实体全字段结构（含暂缓字段位，先建后空）、初始固定 4 人（战士/盗贼/法师/牧师，推断建议）、简化招募池（每日刷新、偏向缺失职业）、升级+职业倾向选择+第 1 档技能解锁、板凳经验分享、战旗损耗回城恢复（当日全额，占位）、重伤休养按天（占位天数）、状态机（健康/休养/恢复）；
- **不做（暂缓存档）**：二转、压力怪癖数值与效果（仅留字段位）、NPC 入会、解雇、完整版招募权重与保留规则、按天缓慢恢复（若 DEMO 试玩反馈要求保留张力再启用）。

## 6. 风险与待专项细化项

- **风险**：① 映射骨架系数未定前战旗无法平衡——案 5 骨架是数值专项案的输入，需尽早启动；② 招募随机性 vs 初始固定队的体验断层（DEMO 固定队上手顺，但招募池价值感知弱——试玩验证）；③ 属性双用途平衡（幸运偏弱，继承全局风险）；④ 「回城当日全额恢复」削弱了宿舍与轮换的意义（DEMO 验证点，若成立则改为按天恢复）；
- **待专项细化**：数值专项案（成长曲线、映射系数、经验分配、招募花费与权重、休养与恢复数值）；案 10（倾向选项与技能池结构）；案 3（训练场档位与分享率的设施侧数值）；案 14（压力怪癖效果，暂缓）。
