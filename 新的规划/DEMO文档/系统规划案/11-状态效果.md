# 案 11《状态效果（BUFF/DEBUFF）系统规划案》

## 1. 系统定位与目标

- **定位**：所有 BUFF/DEBUFF 的**唯一定义与结算中枢**——技能（案 10）、地格（案 9）、检定带入（案 8）、药水食物（案 4，暂缓）多来源统一登记，防止「各技能各写各的效果」导致规则打架；奇术师玩法的直接地基。
- **服务的核心体验**：小队战棋的策略感（状态叠加与结算时机的博弈）。

## 2. 机制细则

### 2.1 状态效果类型池（推断框架）

| 大类 | 说明 | 示例 |
|---|---|---|
| 属性修正 | 一级/二级属性增减 | 盾墙（护甲↑）、虚弱（伤害输出↓；=§2.5 诅咒系「虚弱诅咒」，P-16 归并——同一效果单一名义，21 案引用侧同） |
| 持续伤害/治疗 | 回合末跳字 | 蚀命诅咒（暗伤）、再生（回血） |
| 行动限制 | 限制移动/行动 | 定身（硬控）、减速（移动力↓）、蛊惑（行动异常） |
| 特殊标记 | 无直接效果，被其他效果/技能引用 | 诅咒标记（完整版） |

命名规范（推断）：效果 id 前缀 `BUFF_ / DEBUFF_`；图标正负色区分。

速度类 BUFF 为**排序专用修正**（速度 ±N、仅作用行动排序），不修改敏捷值本身、不入「一级属性修正」类——不连带闪避/暴击等敏捷派生（17 案 §3.2，17-C19·第三轮拍板组 2026-09-22）。

### 2.2 状态施加与叠加互斥规则（本案核心规则；规则 1 同名不叠加已定稿 v0.5.2，其余为推断）

**前置：状态施加两段判定（#5 已定稿）**——以敌方为目标的状态施加（技能 DEBUFF、诅咒/幻术/蛊惑系全部适用）走两段判定（攻击型技能的攻击命中判定与状态施加第一段命中判定独立各掷一次——最坏 3 掷，【已定稿·用户拍板 2026-09-22·二审拍板组】，案 9 §2.4 同口径）：
1. **第一段：命中判定**——施放者命中率（含技能自带命中修正，案 10）对目标闪避率（案 9 命中框架同构）；未命中=施加失败，仅技能资源照常消耗；
2. **第二段：抗性减免**——命中后按目标「异常状态抗性」计算减免；减免方式（降低施加概率 / 缩短持续回合 / 削减效果强度）归数值专项案裁定，本案锁定「两段顺序 + 各自读数属性」。

- 己方目标的正面 BUFF：免命中判定，直接生效并过叠加/互斥检查（已定稿）；
- 地格来源状态（毒沼等）：直接生效、不过两段判定（已定稿；是否补抗性段完整版试玩定）；**技能生成的地格**——游侠陷阱等（案 9 动态地格接口）——同此口径：敌方踩中触发时直接生效，不过两段判定（已定稿 D7）；**伤害类地格（游侠陷阱）同步免减免轨（D7 口径扩展·已定稿·用户拍板 2026-09-22·第三轮拍板组）：触发伤害按固定值直接结算，护甲/抗性/穿甲均不参与——与持续伤害类「生效后不过减免轨」同构（17 案 §3.4）**；
- 检定带入的开局状态（案 8 参数包）：检定已定成败，不再过两段判定（原文口径保持）。

**叠加与互斥规则**：

1. **同名不叠加**：重复施加同名效果=持续时间取较大者（不叠层、不重置为固定值；「刷新」表述废除，照改）；
2. **同类叠加上限**：同向属性修正效果最多并存 2 层（不同来源可并存，占位上限）；
3. **互斥组**：同组效果后施加覆盖前者（例：控制组——**定身/蛊惑互斥**（同属行动限制类控制效果，占位）仅存其一；两者均在 §2.6 DEMO 池内（构成互斥对示例））；
4. **相反效果共存抵消**：同属性正负效果可同时挂载、计算时抵消（占位口径）。

### 2.3 时间计法与结算时机

- 计法以**回合**为单位（战斗内）；跨战斗一律不保留：所有状态（含检定带入的开局增益）在战斗结束时清除，无例外（原「例外」表述为逻辑误植，照改改写）；
- **递减时序（已定稿·用户拍板 2026-09-22·第五轮拍板组）**：**本回合内新施加的状态当回合末不递减，递减时点=其生效回合的回合末**（施加即生效，但须跨过一个完整回合末才首次递减）——防短持续状态在施放回合末即被清零空转（蛊惑「下回合行动异常 1 回合」、寒冰锁链定身 1、敌方施加减速 1 回合等按此口径获得完整生效窗口）；
- 结算挂案 9**回合末流程**：统一处理持续伤害/治疗、持续时间递减（按上条时序）、到期移除；
- 地格型状态：站位期间持续（草丛类站上生效离开失效）；毒沼类每回合末结算。

### 2.4 多来源统一登记

| 来源 | 登记方式 |
|---|---|
| 技能（案 10） | 技能定义引用状态 id，施放时登记 |
| 状态地格（案 9） | 地格定义引用状态 id，进入/站位时登记 |
| 检定带入（案 8） | 开局参数包指定状态 id，战斗载入时登记 |
| 药水/食物（案 4） | 暂缓；字段预留 |
| 装备词条（完整版） | 存档预留 |

施加时一律过 2.2 叠加/互斥检查；查询/移除/结算为三个标准动作。

### 2.5 奇术师 DEBUFF 专用设计区（推断草案，强度经技能属性权重表由意志主导，#17）

| 系 | 效果草案 |
|---|---|
| 诅咒系 | 蚀命诅咒（回合末持续伤害）；腐蚀诅咒（持续伤害+护甲↓）；虚弱诅咒（伤害输出↓） |
| 幻术系 | 迷障（命中↓）；幻影缠身（闪避↓/受暴击概率提升——状态内嵌效果，不入二级属性表，照改） |
| 蛊惑系 | 蛊惑（行动异常：随机移动/攻击偏差——软控标志效果） |

（蛊惑系「迟滞（移动力↓）」删除，并入基础池「减速（移动力↓）」——同状态 id，「迟滞」名废除，照改；幻术系 DEMO 不入池，见案 10 说明。）

与法师硬控的体验区分：奇术师削弱**效率与准度**、逐步累积；法师剥夺**行动本身**、瞬时强效（定身建议短持续/高消耗，数值案平衡）。

### 2.6 DEMO 基础池规格

约 10-15 个效果实例：六职业 DEMO 技能所需状态（盾墙/疾步/定身/减速/陷阱状态/诅咒系 1/蛊惑 1）+ 地格 2-3 种 + 检定带入 2 种（伏击增益/暴露减益）——**DEMO 实例=暴露减益 1 处（18 案链二被伏击出口开局参数包，18-C7·第三轮拍板组 2026-09-22；检定带入免两段判定、直接生效，见 §2.2）；伏击增益入池、完整版伏击题材事件启用**。

| 表 | 字段建议 |

## 4. 与其他系统的接口

- **输入**：案 10（技能施加）、案 9（地格施加+回合末结算调用）、案 8（开局参数包施加）、案 4（暂缓）；
- **输出**：属性修正→案 9/5（战斗数值计算读取）；回合末结算清单→案 9；状态列表→案 15（UI）；
- **依赖**：案 9（结算时机）；**被依赖**：案 8/9/10、案 4（暂缓）、案 14（怪癖效果可复用状态框架——完整版另议）。

## 5. DEMO 口径

- **做**：2.6 基础池全量；叠加/互斥规则（**同名取较大者**（§2.2 规则 1 定稿口径）+叠层上限 2+至少 1 个互斥组）；回合末结算；检定带入 2 种；状态 UI 图标+Tooltip；
- **不做（暂缓）**：战斗外状态、特殊标记消费链、装备词条状态、怪癖复用框架。

## 6. 风险与待专项细化项

- **风险**：① 叠加规则复杂度 vs 玩家理解（UI 一眼看懂——案 15 重点）；② 互斥组设计遗漏导致组合爆炸；③ 状态残留类缺陷（战斗结束未清除——验收用例覆盖）；④ 奇术师 DEBUFF 数值弱感知（叠满不如法师一个火球——DEMO 试玩重点验证「绞杀节奏」是否成立）；
- **待专项细化**：数值专项案（全部状态数值）；案 15（状态 UI 信息架构）；案 14（怪癖复用框架，暂缓）。
