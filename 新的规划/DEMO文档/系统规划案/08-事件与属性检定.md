# 案 8《事件与属性检定系统规划案》

## 1. 系统定位与目标

- **定位**：CRPG 层核心——事件数据结构与 D20 检定的统一中枢；分支出口（含改写战旗开局）的唯一出口规范。
- **服务的核心体验**：掷骰抉择的代入感（随机性可视化 +「我的选择有后果」）。

## 2. 机制细则

### 2.1 事件数据结构（节点图模型，推断框架）

- **事件链** = 有向节点图；**节点** = 叙述文本 + 选项列表；**选项** = 行为定义 + 后果出口；
- **四类分支出口（正式入档）**：
  - A 结算奖励差异：直接结算资源差异（货币/经验/耗时/损耗）；
  - B 进入不同战旗开局：输出「开局参数包」→案 9；
  - C 解锁隐藏内容：隐藏区域/秘密标记（完整版：暗线挂钩）；
  - D 影响结局与 NPC 关系（**DEMO 外·暂缓**，字段建好不启用，归案 13）；
- 纯选择选项（无检定）允许存在；条件选项（属性≥阈值/持有物品才显示，完整版存档）。

### 2.2 D20 检定细则（已定稿骨架展开）

- **骰制（已定稿）**：可见骰 D20，检定值 = 属性调整值 + D20 结果，对比事件难度等级；**骰出 20 = 大成功、骰出 1 = 大失败**；
- **属性调整值口径（推断）**：一级属性原始值折为调整值（如每 2 点属性 = +1，占位示例）——换算式留数值专项案；
- **难度分级建议（推断，占位五档）**：极易 5 / 容易 8 / 普通 11 / 困难 14 / 极难 17；
- **大成功/大失败效果类型（推断）**：大成功=超额奖励/额外信息/最优分支；大失败=额外损失/惩罚遭遇/局势恶化——**均不得违反「失败也推进」原则**。

### 2.3 检定执行者交互流程（已定稿：自动取最高，可改派）

```
选项确认 → 展示全队该属性值排序（默认高亮最高者）
→ 玩家确认或改派 → D20 掷骰演出 → 四档结果
→ 按结果跳转对应出口
```

### 2.4 「失败也推进」原则（推断，落地硬规则）

- 每个检定选项**必须定义成功与失败两条去向**，失败去向不得为死路（无后续、无补偿、无替代路径即不合规）；
- 失败路径合规形式：替代收益（信息/小额补偿）、代价路径（额外战斗/损耗/+1 天耗时）、绕行路径（不同分支继续推进）；
- 大成功/大失败在成功/失败去向基础上叠加增量修饰（不做第五条独立去向，控制文案量）。

### 2.5 检定结果 → 战旗开局改写接口（开局参数包）

**可改写维度清单（推断建议，字段固定防返工）**：

| 维度 | 可选值示例 |
|---|---|
| 先手权 | 我方全员先动 / 敌方全员先动 / 正常掷速 |
| 敌方初始分布 | 分散 / 集结 / 背对（可偷袭） |
| 初始地形状态 | 预设状态地格生效（如我方高地） |
| 初始 BUFF/DEBUFF | 伏击=我方增益或敌方减益（经案 11 施加） |
| 敌方构成微调 | 数量增减 / 精英替换（低幅度） |
| 我方站位 | 被夹击 / 常规 |

参数包由事件选项填充、案 9 接收应用；未填维度走默认值。

### 2.6 耗时代价机制（推断，对接案 2）

选项可标注「耗时 +1 天」：结算时向案 2 申报，出征总耗时累加——稳妥路线费时、冒险路线省时有风险。

## 3. 数据与配置需求

| 表 | 字段建议 |
|---|---|
| 事件链 | 链 id、名称、关联委托模板 id / 触发点 id、入口节点 id |
| 事件节点 | 节点 id、叙述文本、选项 id 列表、结算文本（按结果四档） |
| 事件选项 | 选项 id、类型（检定/纯选择/结算）、检定属性、难度等级、去向映射（成功/失败节点或出口）、大成功与大失败修饰引用、出口类型（A/B/C/D）、奖励引用、开局参数包、耗时天数、显示条件（完整版） |
| 隐藏内容标记 | 标记 id、解锁条件、归属（完整版） |

## 4. 与其他系统的接口

- **输入**：案 7（触发）、案 5（全队属性查询）；
- **输出**：开局参数包→案 9；状态施加→案 11；奖励→案 4/5；耗时申报→案 2；D 类出口→案 13（暂缓）；隐藏标记→案 12（完整版）；
- **依赖**：案 5/7；**被依赖**：案 6（委托关联）、案 9（参数包）、案 13（多结局挂钩，暂缓）。

## 5. DEMO 口径

- **做**：事件链 2-3 条 × 3-5 分支；四档结果全套文案模板；自动取最高+改派 UI 流程；开局参数包演示至少 2 种维度（先手权、敌方分布）；耗时代价 1 处演示；D 类出口字段建好不启用；「失败也推进」作为文案验收硬标准；
- **不做（暂缓）**：条件选项、隐藏标记实效、大范围属性调整值曲线（用占位换算式）。

## 6. 风险与待专项细化项

- **风险**：① 文案量与结构规范的平衡；② SL 读档赌博（靠「失败也推进」+幸运兜底缓解）；③ 开局参数包字段一旦定版不可轻改；
- **待专项细化**：数值专项案（调整值换算式/难度校准）；事件专项案（DEMO 全部事件链文案+完整版生产规范）；案 13（D 类出口效果定义，暂缓）。
