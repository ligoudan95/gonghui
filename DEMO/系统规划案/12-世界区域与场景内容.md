# 案 12《世界区域与场景内容规划案》

## 1. 系统定位与目标

- **定位**：世界内容的组织层——区域清单、解锁条件与场景内容定义；案 7 地图与案 6 委托的**区域 id 权威来源**；
- **服务的核心体验**：三支柱的空间舞台（「世界在变大」的探索期待）。

## 2. 机制细则

### 2.1 区域清单与解锁（推断占位，DEMO 前三行生效：city/village/mine）

| 区域 id | 名称 | 定位 | 解锁条件（推断） | DEMO |
|---|---|---|---|---|
| city | 光辉城 | 城内枢纽（六场所+路人）（完整版；DEMO 仅协会入口，主场景为独立公会，#11） | 初始 | 含（简化） |
| village | 村子 | 安全中继，连接矿洞 | 初始 | 含 |
| mine | 矿洞 | 明线主舞台：多层网状 | 初始（一层）；深层随公会等级（完整版） | 含一层 |

### 2.3 区域-地图-委托关联结构

```
案 12 区域表（区域 id 权威源）
   ↑ 引用                    ↑ 引用
案 7 地图定义.所属区域 id 列表（多值）    案 6 委托模板.目标区域 id
```

区域表是唯一权威：地图与委托只引用区域 id，不自行定义区域属性（防双源不一致）。区域危险度为区域表唯一持有字段，案 7 地图与遭遇权重只引用（照改）。

### 2.4 场景内容规格（推断建议）

- **光辉城（DEMO）**：**DEMO 主场景=公会（设施交互：宿舍/训练场等独立场景入口）【已定稿·用户拍板 2026-09-22·P-8】；公会独立于光辉城（#11 已定稿）；光辉城在 DEMO 中仅保留冒险者协会一个入口（委托板+招募池）**。其余五场所不做出（备选：不可进入的外观展示，成本允许时加）；完整版=可行走城内大场景，公会仍为独立主场景；
- **村子（DEMO）**：安全中继小场景，作为探索图（案 7 DEMO 图）入口段：1-2 个轻事件点、无战斗；**全亮（不设迷雾）**——#25 战争迷雾对村子段不适用（安全中继+教学对照；迷雾集中矿洞一层，案 7 §2.1）；
- **矿洞一层（DEMO）**：案 7 DEMO 探索图主体（事件 2-3、必然遭遇 1、宝箱 2-3、暗门 1）。

### 2.5 完整版区域方向存档（推断）

- **矿洞多层主题分化**：浅层矿道（教学低危）→ 中层巢穴（怪物聚集、网状岔路）→ 深层（异变源头、明线高潮）——逐层呼应混合反转主线（案 13）；
- **大森林高自由度**：大图+高随机遭遇+全类型资源点+隐藏内容聚集地（原文：「里面什么东西都有」）。

### 2.6 美术方向（推断占位）

光辉城暖色市井风 / 村子田园风 / 矿洞冷暗岩穴风（火把光源）/ 大森林深绿幽邃风。

## 3. 数据与配置需求

| 表 | 字段建议 |
|---|---|
| 区域表 | 区域 id、名称、定位描述、解锁条件（公会等级档引用案 3）、危险度档、场景资源引用、色调方向、隐藏内容标记引用（完整版存档——案 8 隐藏标记输出口）（地图归属由案 7 地图侧「所属区域 id 列表」反查派生，本案不持列表——防双源，已定稿 P3） |
| 场所表 | 场所 id、所属区域、名称、功能类型（**多值**：商店/委托/招募/剧情——协会=委托+招募）、挂接系统标记、场景入口资源 |
| NPC 摆位表（存档） | NPC id、位置、所属场景、关联台词 id（案 13，暂缓）、外观资源 |

## 4. 与其他系统的接口

- **输入**：案 3（公会等级→解锁判定）；
- **输出**：区域 id → 案 7/6；**场景资源规格 → 案 20；场景导航/入口 UI → 案 15**（第十轮盲审 L18 消歧，原「场景资源 → 案 15」指向过宽——资源规格归视觉专项案、导航与入口交互归 UI 案）；NPC 摆位 → 案 13（暂缓）；
- **依赖**：案 3；**被依赖**：案 6/7/13/15。

## 5. DEMO 口径

- **做**：区域表结构建立（大森林行留空存档）、光辉城=公会场景+协会单入口、村子+矿洞一层场景（按案 7 DEMO 图规格）、冒险者协会双功能入口（委托板+招募池）；
- **不做（暂缓）**：可行走城内大场景、四购物场所、城主大厅、路人 NPC、矿洞深层、大森林。

## 6. 风险与待专项细化项

- **风险**：① DEMO 协会单入口的世界感单薄（用文案与 UI 补「城」的想象；玩家必须一眼知道去哪接委托——案 15 验证）；② 场景制作量（完整版大头）；③ 区域解锁与内容供给不匹配（完整版空档期）；
- **待专项细化**：视觉专项案（场景概念与资源规格）；案 13（路人与城主大厅内容）；案 15（场景导航与入口 UI）。
