# 《未定名：冒险者工会》一小时 DEMO 策划文档

> 文档用途：评估并界定一个约 60 分钟可完成、可反复测试的垂直切片 DEMO 的实际内容工作量。  
> 关联设计案：[冒险者工会游戏初步设计案.md](../冒险者工会游戏初步设计案.md)  
> 估算口径：小型独立团队，使用现成引擎与成熟基础框架；工时为“有效人日”，不包含招聘、引擎学习、长时间等待外包和发行准备。

---

## 1. 结论摘要

### 1.1 推荐 DEMO 形态

建议制作一个**单章节、单区域、单次完整行动周期**的垂直切片，而不是把完整游戏的所有系统都做成缩小版。

玩家在约 45–75 分钟内完成以下体验：

> 接收调查委托 → 管理有限的冒险者队伍 → 结识并推进特殊 NPC 支线 → 选择是否调用强力助力 → 在节点式大地图探索 → 进入 1 场主战棋与 0–1 场短遭遇 → 带着成功或失败结果返回工会 → 处理队伍短回响与特殊 NPC 支线反馈 → 得到下一次行动的钩子。

**建议目标时长：**首次游玩 60 分钟左右；熟悉系统后 35–50 分钟可完成；保留一条可接受失败的结果路径。

### 1.2 工作量结论

在“基础框架已有、核心系统不需要从零研发”的前提下，一个能体现本项目核心卖点的 DEMO，建议按以下规模评估：

| 方案 | 适用情况 | 总工作量（有效人日） | 约 5 人团队制作周期 |
| --- | --- | ---: | ---: |
| 极简验证版 | 只验证循环，不追求公开展示品质 | 90–130 | 5–7 周 |
| **紧凑内部展示版** | 具备完整一小时体验，可用于内部评审或小范围试玩；大量复用框架与资产 | **180–260** | **9–13 周** |
| **完整展示版** | 在紧凑版基础上补足更完整的美术、音频、测试与失败恢复打磨 | **240–430** | **12–18 周** |
| 对外发布版 | 面向公开下载，具备较完整的设置、兼容性、稳定性和反馈设施 | 300–450 | 15–22 周 |

以上为“有效人日”而非自然日。多人并行时，内容依赖、返工和整合会使自然周期高于简单除法。若程序基础框架、战棋框架或美术资产管线尚未存在，应在对应方案上额外增加 30%–70%。

**本文件后续以 180–260 有效人日的紧凑内部展示版为主要拆解对象；第 6 章同时给出完整展示版的岗位级工作量。**

### 1.3 最重要的范围判断

一小时 DEMO 最多只需要证明以下四件事：

1. 工会筹备会改变玩家对远征的期待与策略。
2. 大地图节点探索会把有限信息转化为路线和目标选择。
3. 战棋不是独立小游戏，而是对前期准备和剧情目标的兑现。
4. 特殊 NPC 支线能提供很强、但有条件和代价的帮助；普通冒险者只提供队伍构筑与轻量情绪反馈。

以下内容不应为了“看起来完整”而加入 DEMO：完整势力系统、多个区域、复杂派遣、全套恋爱流程、随机生成任务、长期经济曲线、大量装备词条和大规模 NPC 网络。

## 2. DEMO 的体验目标与验收定义

### 2.1 玩家离开 DEMO 时应记住什么

玩家应能说出：

- 我经营的是一支有职业、伤病、疲劳和队伍氛围差异的冒险者队伍。
- 我可以先收集信息，再决定走安全路线还是高风险捷径。
- 特殊 NPC 不是普通冒险者，而是有个人问题、独立支线和稀缺能力的外部人物。
- 我可以不做特殊 NPC 支线，但做了之后能用更强的办法解决问题。
- 战棋中的目标不只是消灭敌人，还要决定救人、取证、追击或撤退。
- 失败不会立即结束游戏，而会改变结算和下一步局面。

### 2.2 DEMO 的完成条件

DEMO 不以“玩家必须完美通关”为完成条件。以下任一结果均视为内容闭环完成：

- 完成主线调查并带回目标物。
- 救出目标但丢失关键证据，进入部分成功结算。
- 主动撤退，保住队伍但让敌对势力获得先机。
- 战棋失败后接受伤病或债务，触发补救钩子。

每条结果都必须到达明确的回城结算，不允许卡在“失败画面”或无反馈的战斗结束处。

### 2.3 推荐单章主题

**主题示例：旧矿道中的失踪调查**

城镇附近的旧矿道发生人员失踪。委托表面上是一次搜救，实际牵涉一项被掩盖的遗迹研究和敌对势力的资源争夺。玩家需要在资金有限的情况下，决定是购买情报、依靠冒险者专长，还是推进某个特殊 NPC 的支线以获得更安全的路线。

这个主题能在一个区域内同时承载：调查、救援、证据、路线选择、战棋目标、特殊 NPC 助力、队伍短回响和多级结算。

## 3. DEMO 范围锁定

### 3.1 玩家流程范围

```mermaid
flowchart LR
    A[开场与工会现状] --> B[查看委托与队伍]
    B --> C[准备：组队、情报、物资]
    C --> D[推进一名特殊NPC支线]
    D --> E[进入单一区域大地图]
    E --> F[调查节点与路线选择]
    F --> G[主战棋：救人/取证/追敌]
    G --> H[结算：成功、部分成功或失败]
    H --> I[队伍短回响与支线反馈]
    I --> J[章节收束与下一钩子]
```

### 3.2 推荐内容清单

| 内容模块 | DEMO 目标规模 | 备注 |
| --- | ---: | --- |
| 工会据点 | 1 个可操作场景或 1 套总览界面 | 不做完整自由行走建筑群 |
| 可出战普通冒险者 | 4 名 | 职业、专长、状态和队伍标签有明显差异 |
| 特殊 NPC | 3 名 | 三人合计覆盖情报/地图、战棋、经营/失败恢复三类助力 |
| 可选特殊 NPC 支线 | 1 条完整 + 2 条首阶段 | 另外两名至少展示个人矛盾与基础助力 |
| 主线委托 | 1 条 | 具备多级结果和回城结算 |
| 普通/势力委托 | 2–3 条 | 其中 1 条可作为情报或资源准备入口 |
| 区域大地图 | 1 张 | 8–10 个节点，玩家实际访问 5–7 个 |
| 主战棋地图 | 1 张 | 目标为救援、取证或追敌，而非单纯歼灭 |
| 短战棋/风险遭遇 | 0–1 张 | 可用事件或快速战斗替代 |
| 设施 | 委托厅、情报室、医务室 | 只开放与本章相关的行为 |
| 资源 | 资金、补给、情报、声望/势力态度 | 不引入复杂生产链 |
| 结果 | 完全成功、代价成功、部分成功、撤退/失败 | 至少实现 3 种可到达结果 |
| 队伍短回响 | 3–5 段 | 短对话、动作或结算评语 |
| 存档 | 自动存档 + 1 个手动存档位 | 对外 DEMO 建议加入 |

### 3.3 建议砍掉的范围

- 第二张区域地图。
- 超过 4 名普通冒险者。
- 超过 3 名特殊 NPC 的完整支线。
- 复杂恋爱确认、排他关系、多结局恋爱演出；推荐版最多保留一次明确的特殊 NPC 关系方向选择。
- 可重复随机委托生成器。
- 次要小队派遣的完整异步系统。
- 多层装备强化、随机词缀、制作配方树。
- 季节、天气、昼夜和完整城镇经济模拟。
- 大量可自由交谈居民。
- 复杂的冒险者两两关系网络。
- 语音全配、完整过场动画和多语言本地化。

## 4. 一小时内容节奏拆解

### 4.1 推荐体验时长

| 阶段 | 首次游玩 | 熟悉后 | 内容目标 |
| --- | ---: | ---: | --- |
| 开场与系统说明 | 5–8 分钟 | 3–5 分钟 | 建立工会处境、委托问题和操作认知 |
| 工会筹备 | 8–12 分钟 | 5–8 分钟 | 选择队伍、购买情报、决定是否推进支线 |
| 特殊 NPC 接触 | 5–8 分钟 | 3–5 分钟 | 展示人物问题和第一项助力 |
| 大地图探索 | 15–22 分钟 | 10–15 分钟 | 访问节点、收集线索、决定路线 |
| 主战棋 | 15–22 分钟 | 10–15 分钟 | 完成多目标战斗或接受失败 |
| 结算与回响 | 8–12 分钟 | 5–8 分钟 | 反馈队伍状态、支线变化和下一钩子 |
| **合计** | **56–84 分钟** | **36–56 分钟** | 首次接近 1 小时，熟练后可快速完成 |

首次游玩超过 75 分钟通常意味着教程、文本或地图回访过长；低于 35 分钟则很可能没有展示经营与支线回流的价值。

### 4.2 心流节奏要求

- 前 10 分钟内必须完成一次“有代价的选择”，例如花钱买情报会减少补给预算。
- 前 20 分钟内必须看到至少一名特殊 NPC 的独特能力，而不是只听背景介绍。
- 主战棋前必须让玩家理解至少两种目标或处理方式。
- 战棋失败后 2 分钟内必须进入可读的后果结算。
- 结束前必须出现下一次行动的钩子，例如支线新阶段、敌人动向或区域变化。

## 8. DEMO 的三个关键内容闭环

### 8.1 闭环一：队伍构筑 → 探索解法

**必须完成的内容工作：**

- 4 名普通冒险者至少有 3 种不同的探索/战斗职责。
- 至少 2 个节点能因不同职业组合提供不同处理方式。
- 不要求某位冒险者与主角建立关系，不设置个人好感门槛。
- 队伍氛围只产生一段短回响或轻微状态，不影响主线通行。

**验证问题：**玩家是否会因为任务目标而调整队伍，而不是永远使用同一套阵容？

### 8.2 闭环二：特殊 NPC 支线 → 强力助力 → 局内反馈

**必须完成的内容工作：**

- 一名特殊 NPC 拥有完整的 3–5 阶段支线，至少包含一次明确抉择。
- 该 NPC 至少提供一种非常强的助力，例如开放隐蔽路线、封锁增援或降低重伤。
- 助力必须有独立次数、冷却、资源、人情或政治代价。
- 不完成支线时，主线仍有基础解法。
- 使用助力后，特殊 NPC 支线或势力状态必须出现可见反馈。

**验证问题：**玩家是否觉得“做支线很值得”，但又不会觉得“不做就没法玩”？

### 8.3 闭环三：战棋目标 → 多级结果 → 回城回响

**必须完成的内容工作：**

- 主战棋至少拥有 2 个互相竞争的目标。
- 至少实现 3 种可到达结果，而非仅胜利/失败。
- 每种结果都产生不同的队伍状态、资源或世界反馈。
- 回城后有普通冒险者短回响和特殊 NPC 支线反馈。
- 结果不依赖恋爱或普通冒险者关系。

**验证问题：**玩家是否能接受“没有完美解决所有目标”并继续下一步？

## 9. 里程碑与验收门槛

### M0：范围与技术可行性（第 1 周）

**完成内容：**

- DEMO 范围锁定，砍项表签字。
- 选定单章主题、4 名普通冒险者、3 名特殊 NPC 的定位。
- 战棋框架、对话/事件框架、地图形式和存档方案确认。
- 主要变量和结果状态字典完成。

**验收门槛：**任何新增需求都必须说明会砍掉什么，避免范围无上限增长。

### M1：灰盒闭环（第 2–4 周）

**完成内容：**

- 玩家可以从开场走到工会、地图、战棋并返回结算。
- 至少 1 个节点、1 场战棋、1 个特殊 NPC 助力可用。
- 使用占位图和占位文本即可。

**验收门槛：**第一次试玩能在 20–30 分钟内完成一轮最小闭环；失败后不会软锁。

### M2：系统与内容接入（第 5–8 周）

**完成内容：**

- 8–10 个节点、主线多级结果、3 名特殊 NPC、队伍短回响全部接入。
- 助力的条件、代价和替代方案可读。
- 普通冒险者状态和队伍氛围对远征产生轻量影响。

**验收门槛：**内部玩家能清楚区分普通冒险者互动与特殊 NPC 深度支线；至少 3 种结果可自然到达。

### M3：美术、音频与体验打磨（第 9–11 周）

**完成内容：**

- 核心界面、地图、角色、敌人、特效和音效替换为目标品质资产。
- 首次游玩引导、结算摘要、日志、自动存档完成。
- 完成第一次外部或跨团队试玩。

**验收门槛：**首次游玩中位时长 45–75 分钟；玩家能说出特殊 NPC 助力的作用与代价。

### M4：稳定性与交付（第 12–13 周）

**完成内容：**

- 修复阻断、软锁、存档、触发和严重表现问题。
- 完成目标平台打包、反馈入口和已知问题说明。
- 锁定 DEMO 版本，不再加入新系统。

**验收门槛：**连续 5 次完整通关/失败路径测试无阻断；关键结果和支线状态可重复验证。

## 10. 资源与成本敏感项

### 10.1 最容易超支的内容

1. **战棋框架从零开发**  
   回合、寻路、技能、目标、AI、撤退、存档和多级结果会同时牵动程序、策划、UI 和测试。

2. **高规格角色资产**  
   7 名重要角色看似不多，但立绘、表情、模型、骨骼、战斗动作和特效会快速膨胀。

3. **分支文本与特殊 NPC 支线**  
   个人故事不是几段对话，而是条件、状态、助力、代价和结局反馈的完整内容链。

4. **“为了完整”加入系统**  
   派遣、恋爱、装备制作、季节和势力系统会带来大量 UI、存档、测试和边界工作。

5. **最后阶段才做可用性**  
   如果前期没有日志、因果提示、失败恢复和自动存档，后期修复成本会很高。

### 10.2 推荐优先级

| 优先级 | 必须保证 | 可降规格方式 |
| --- | --- | --- |
| P0 | 一小时闭环、主战棋、多级结果、特殊 NPC 助力、基础存档 | 占位美术、无配音、减少节点 |
| P1 | 4 名冒险者差异、队伍短回响、3 名特殊 NPC、引导和日志 | 减少支线阶段、复用场景与动画 |
| P2 | 对外品质 UI、音频、失败恢复演出、特殊过场 | 使用授权资源、静态演出、减少特效 |
| P3 | 恋爱明确演出、多语言、全语音、自由探索建筑、额外结局 | DEMO 中全部砍掉或只留钩子 |

### 10.3 可以外包的工作

- 通用 UI 图标和非关键道具。
- 环境贴图、背景装饰和地图装饰物。
- 部分音效、音乐和混音。
- 非关键 NPC 的短句校对或本地化。
- 测试执行和兼容性测试。

### 10.4 不建议外包的工作

- 核心循环、特殊 NPC 支线逻辑和助力条件。
- 主战棋目标、失败恢复和多级结果。
- 变量字典、存档结构和系统间状态回写。
- 关键角色的核心人设与支线决策。
- 最终体验节奏、可玩性调优和范围取舍。

## 11. 质量验收指标

### 11.1 内容完整性

- [ ] 玩家可以在 3 次以内理解“工会筹备—远征—结算”的流程。
- [ ] 至少 1 次筹备选择会改变地图或战棋条件。
- [ ] 至少 1 名特殊 NPC 的支线从相遇推进到助力反馈。
- [ ] 3 名特殊 NPC 都能被识别为有个人问题的角色，而不只是功能商店。
- [ ] 普通冒险者之间有短互动，但没有复杂关系图、主角好感或恋爱路线。
- [ ] 战棋至少有 2 个竞争目标和 3 种可到达结果。
- [ ] 不使用特殊 NPC 助力时，主线仍然可完成。
- [ ] 失败、撤退和部分成功都有清楚结算。

### 11.2 心流与可读性

- [ ] 首次游玩中位时长在 45–75 分钟。
- [ ] 任何关键助力的效果、条件、成本和限制都能在调用前看到。
- [ ] 玩家能解释自己为什么进入当前战棋和为什么得到当前结果。
- [ ] 失败不是突然结束，而是 2 分钟内进入可理解的后果。
- [ ] 回城结算后，玩家能指出至少一个想继续处理的事项。
- [ ] 不需要查外部攻略才能理解主线基础通路。

### 11.3 稳定性

- [ ] 主线所有结果路径都能完成自动存档。
- [ ] 支线延后、支援耗尽和任务失败不会造成软锁。
- [ ] 战棋重试和接受结果两种选择都可用，或有明确设计说明。
- [ ] 关键变量可通过调试工具检查。
- [ ] 连续 5 次完整流程测试无阻断。

## 12. 砍项规则与变更控制

DEMO 制作期间，任何新增需求都必须回答以下问题：

1. 它是否直接验证四个核心卖点之一：经营准备、大地图探索、战棋决策、特殊 NPC 助力？
2. 它是否会在一小时内被玩家看见并理解？
3. 它是否复用现有框架和资产？
4. 它会增加多少 UI、存档、测试和状态边界？
5. 为它加入多少工作量，就必须砍掉哪一项现有内容？

若不能回答第 1、2 项，默认不进入 DEMO。若预计增加超过 10 人日，应在制作评审中重新确认范围。

### 推荐变更顺序

- 优先增加结果可读性、因果提示和失败恢复。
- 其次增加现有 NPC 支线的深度，而不是新增 NPC 数量。
- 再其次增加战棋目标或地图路线的变化。
- 最后才考虑新系统、新区域、新职业或新 UI 页面。

## 13. 最终建议

### 13.1 推荐采用的 DEMO 规格

建议采用**内部展示至小范围试玩级别**的紧凑推荐方案：

- 1 个工会据点。
- 4 名普通冒险者。
- 3 名特殊 NPC。
- 1 条完整特殊 NPC 支线，2 条首阶段支线。
- 1 条主线调查委托，2–3 条准备委托。
- 1 张 8–10 节点的大地图。
- 1 张主战棋地图，0–1 场短遭遇。
- 3 种以上多级结果。
- 中文文本约 18,000–30,000 字。
- 无全量配音，音乐与音效采用精选方案。
- 优先复用基础战棋、对话、UI 和角色动画框架。
- 预算按 180–260 有效人日作为内部验证起点，按 240–430 有效人日作为更完整展示版预留。

### 13.2 不能牺牲的内容

如果制作时间不足，宁可减少节点、文本长度和美术规格，也不要砍掉：

- 一次完整的工会—远征—结算循环。
- 一名特殊 NPC 的完整支线与强力助力。
- 不使用助力时的基础主线解法。
- 主战棋的多目标和多级结果。
- 失败或撤退后的可继续状态。
- 普通冒险者的队伍差异与至少一组轻量情绪互动。

### 13.3 DEMO 的判断标准

这个 DEMO 是否成功，不取决于它包含多少系统，而取决于玩家是否在一小时内经历了清晰的因果链：

> **我为了一个任务管理队伍 → 我为了降低未知而准备情报或支援 → 我在地图上做出路线判断 → 我在战棋中决定优先保护什么 → 我带着结果回到工会 → 我看见队伍和特殊 NPC 受到不同影响 → 我自然想知道下一次还能怎么做。**

只要这条因果链成立，DEMO 就已经完成了对正式版核心体验的有效验证；其余系统应留到后续开发，而不是在一小时样片中平均摊薄制作资源。
