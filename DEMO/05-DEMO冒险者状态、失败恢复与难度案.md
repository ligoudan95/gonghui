## 1. 目标与边界

本 DEMO 只用四名普通冒险者展示“为什么要调度队伍”，不做复杂关系模拟。主角是会长兼领队，不是第四名战棋单位；三人出战、第四人留守的取舍必须可见，但不能因为某种状态组合让玩家失去主线资格。

### 1.1 冻结规则

- **D05-01 [冻结]** 工会提供 4 名普通冒险者，每次远征正好选择 3 名出战；主角不占棋子槽。
- **D05-02 [冻结]** 伤病 0/1/2 分别表示健康/轻伤/重伤；重伤禁止出战。
- **D05-03 [冻结]** 疲劳范围 0–100；出战 +25，留守在周期关闭时 -35；疲劳 ≥80 禁止出战。
- **D05-04 [冻结]** 压力范围 0–100；士气范围 0–100，初始士气 60；队伍氛围为派生文字，不是可消费资源。
- **D05-05 [冻结]** 轻伤一个完整留守周期降为健康；重伤先经过一个留守周期降为轻伤，再经过下一个留守周期降为健康。
- **D05-06 [冻结]** 本周期出战者不享受本周期免费留守恢复；出战后新伤最早下周期计恢复。
- **D05-07 [冻结]** 默认无随机永久死亡；失败可以产生长期压力或债务，但不能把 DEMO 变成读档竞赛。
- **D05-08 [冻结]** 协作、士气和氛围的合计软修正不超过 ±10%，不能取消护送、搬证物、撤退和主线基础动作。
- **D05-09 [冻结]** 全员不适、零资金或零补给时提供不依赖现金、NPC 或健康单位的桌面恢复服务；服务推进周期并产生可见机会/债务/声望代价，不净增可支配资产。
- **D05-10 [冻结]** 难度在 `PREP_LOCKED` 锁定；三档基础奖励相同；帮助与可及性设置不重置战斗。

## 2. 四名冒险者卡

具体姓名和美术可以后续调整，但职责差异、状态字段和基础动作必须保持。

| ID | 职责 | 探索专长 | 战斗定位 | 初始状态 | 队伍调度价值 |
|---|---|---|---|---|---|
| `ADV-01` | 盾卫 | 搬运、护送、承受环境压力 | 前线保护/拖延 | 伤病0、疲劳10、压力15、士气60 | 保护证人、承接高风险路线 |
| `ADV-02` | 侦察者 | 足迹、机关、路线识别 | 视野/标记/先手 | 伤病0、疲劳15、压力20、士气60 | 提前识别巡逻和撤退条件 |
| `ADV-03` | 工匠 | 工具、封锁、证据处理 | 环境交互/控制 | 伤病0、疲劳5、压力10、士气60 | 处理封印和证据箱 |
| `ADV-04` | 医护/支援者 | 急救、安抚、露营 | 恢复/辅助/低伤害 | 伤病0、疲劳20、压力25、士气60 | 降低状态代价，留守时保持恢复能力 |

这些职责是推荐输入，不是硬门票：

- 任意三人只要状态合法，都能完成至少一条主线基础路线。
- 缺少侦察者可能多花 local_tick；缺少工匠可能消耗补给；缺少盾卫可能在救援中承担更高伤病风险；缺少医护可能更依赖回城恢复。
- UI 显示“更慢、更贵或更危险”，不显示“关系不足/职业不允许”。

### 2.1 主角边界

主角可以：

- 接受/拒绝任务。
- 选择队伍、路线、政策和支援。
- 在战棋中决定目标优先级和撤退。
- 通过会长指令改变可见信息和决策窗口。

主角不拥有：

- 战棋单位、HP、伤病、疲劳、行动点。
- 冒险者经验和装备槽。
- 代替重伤成员出战的隐形能力。

## 3. 状态模型

```text
AdventurerState
  adventurer_id
  injury_level: 0 / 1 / 2
  fatigue: 0..100
  pressure: 0..100
  morale: 0..100
  deployed_this_cycle: bool
  pair_tags[]
  short_echo_tags[]
  recovery_eligibility
```

### 3.1 状态阈值

| 状态 | 区间/档位 | DEMO 效果 | 是否硬锁 |
|---|---|---|---:|
| 疲劳 | 0–39 | 无效率修正 | 否 |
| 疲劳 | 40–59 | 行动效率 -5% | 否 |
| 疲劳 | 60–79 | 行动效率 -10% | 否 |
| 疲劳 | 80–100 | 显示“不适” | 是，禁止新出战 |
| 压力 | 0–24 | 放松 | 否 |
| 压力 | 25–59 | 紧张，结算说明来源 | 否 |
| 压力 | 60–79 | 紧绷，协作贡献降低 | 否 |
| 压力 | 80–100 | 临界，触发一次恢复提示/短回响 | 否，不拒绝主线 |
| 士气 | 0–19 | 低落，软协作负向 | 否 |
| 士气 | 20–39 | 消沉，回响提示 | 否 |
| 士气 | 40–79 | 稳定 | 否 |
| 士气 | 80–100 | 振奋，软协作正向 | 否 |
| 伤病 | 0 | 健康 | 否 |
| 伤病 | 1 | 最大 HP -10%基线 | 否，可出战 |
| 伤病 | 2 | 重伤，不能出战 | 是，仅出战 |

所有值由状态服务裁剪；事件不能写入 -1 疲劳、101 压力或伤病 3。

### 3.2 状态影响上限

- 疲劳档只取最高档，不重复叠加疲劳标签。
- 轻伤最大 HP -10%只应用一次。
- 协作、士气、压力和氛围先合计，再裁剪到 -10%..+10%。
- 软修正只能影响行动效率、普通伤害交换、可选目标窗口或资源代价。
- 关键护送、撤退、搬证物、基础路线和主线确认不被状态禁用。

## 4. 组队和留守

准备界面显示 4 名成员和 3 个槽位。确认出发时：

1. 选择正好 3 名成员。
2. 检查重伤和疲劳 ≥80。
3. 记录 `selected_party_ids` 和 `deployed_this_cycle=true`。
4. 未出战成员记录 `deployed_this_cycle=false`。
5. 写入出发快照，远征过程中不允许直接换入第四人。

留守成员可以：

- 在周期关闭获得一次疲劳/压力/伤病恢复。
- 作为工会岗位提供轻量信息或医护建议，但 DEMO 不额外模拟复杂产出。
- 触发一段与远征结果相关的短回响。

出战成员即使中途撤退或战败，本周期仍按出战处理，不获得留守恢复。

---

## 5. 恢复和伤病进度

### 5.1 基线恢复

周期关闭时，对 `deployed_this_cycle=false` 的成员应用一次：

- 疲劳 -35。
- 压力向 0 方向 -15（低于 0 按 0）。
- 士气向 60 方向移动 10 点。
- 轻伤 1 → 0。
- 重伤 2 → 1。

下一个仍然留守的周期才将伤病 1 → 0。周期关闭事务幂等，重复点击不重复恢复。

### 5.2 现场医疗

- 普通医护者的职业动作可以阻止一次升级或提供临时战斗恢复，具体由 D04 关卡配置。
- 流动医师支援可将本次战斗造成的重伤降为轻伤，不能清除长期伤病。
- 免费战棋重试恢复到战斗开始的伤病状态；未接受的临时医疗不保留。
- 已接受结果后，回城医疗以 DEMO-02 的资源/债务规则结算，不能用支援重新打开战棋。

## 6. 全员不适和桌面恢复

合法出战人数少于 3 时，界面不显示“游戏结束”，而显示：

```text
当前无法组成三人远征队。
可选：桌面恢复（推进一个周期，产生明确机会/债务/声望代价）。
```

桌面恢复：

- 不要求现金、特殊 NPC、健康成员或补给。
- 不发资金、补给、经验、物品或随机奖励。
- 对留守恢复规则进行一次合法结算；本周期重复调用被拒。
- 若资金不足以付维护，按 DEMO-02 写入债务，不把资金变成负数。
- 生成下一周期可继续的基础入口。
- 不自动完成主线、不自动获得证据、不自动改变战棋胜负。

如果四人都重伤：

- 本周期不能出战，必须使用桌面恢复或读取旧档。
- 恢复后重伤成员降到轻伤，但疲劳可能仍高于出战阈值；需要继续留守。
- 系统不得要求玩家先有健康角色来完成恢复任务。

如果四人都疲劳 80 以上但没有重伤：

- 可使用桌面恢复，留守恢复后疲劳降 35。
- 若仍少于三人低于 80，继续下一周期恢复；每次只推进一次世界周期，不发经济收益。

## 7. 队伍氛围和短回响

氛围是由三人平均士气、压力差异和最近标签派生的文字：

- 平稳：平均士气 ≥50，压力无临界。
- 振奋：平均士气 ≥75 且最近有成功互助。
- 紧绷：平均压力 ≥50 或近期撤退。
- 低落：平均士气 <40 或出现重伤/失败。

队伍氛围：

- 只影响一段短回响、结算解释和 ±2%以内的协作贡献。
- 不产生资金、补给、经验和支援次数。
- 不维护冒险者两两关系图。
- 默认一个周期后消退或被新标签覆盖。
- 不成为委托开放、主线通行、恋爱或永久离队条件。

DEMO 短回响建议：

1. 盾卫掩护证人后，医护者表达感谢，士气 +3。
2. 侦察者和工匠争论是否走捷径，压力 +4，下一周期消退。
3. 撤退后队伍讨论“保住人还是保住证据”，提供玩家原因回顾。
4. 完全成功后，留守成员整理证据，显示队伍组织感。

## 8. 难度配置

| 维度 | 辅助 | 标准 | 挑战 |
|---|---|---|---|
| 信息提示 | 显示更多风险和目标因果 | 显示主要因素 | 显示必要信息和不确定项 |
| 敌方行动 | 目标优先级简单 | 标准 | 更积极追击和增援 |
| 伤病后果 | 失败更偏轻伤/压力 | 基线 | 更偏重伤/债务，但仍可继续 |
| 随机幅度 | 次要随机较窄 | 基线 | 次要随机较宽，不影响主线保底 |
| 基础报酬 | 与标准相同 | 与辅助相同 | 与辅助相同 |
| 结算提示 | 详细解释 | 标准解释 | 仍显示不可逆后果类别 |

难度操作：

- 开场默认标准；出发前可切换。
- `PREP_LOCKED` 成功后锁定。
- 战棋行动和结果预览中不能切换。
- 下一周期可调整。
- 帮助高亮、字体、速度、动画跳过可随时改，不重置战斗或随机流。
- 低难度的正常奖励不是漏洞；奖励表只由任务目标和结果等级决定。

## 9. 失败结果和恢复映射

| 结果 | 建议状态后果 | 恢复入口 |
|---|---|---|
| 完全成功 | 出战成员疲劳 +25，最多一名轻伤 | 周期关闭留守恢复 |
| 代价成功 | 一名轻伤/重伤、压力上升、补给耗尽之一 | 医师/回城/留守 |
| 部分成功 | 疲劳 +25，士气 -5，敌方警戒 | 补救任务或桌面恢复 |
| 撤退 | 队伍保全，压力 +8，证据可能丢失 | 周期关闭和下一钩子 |
| 失败继续 | 重伤/债务/声望 -1 的组合，不能全部随机叠满 | 桌面恢复、补救、NPC服务 |

失败后不能同时让四名成员永久离队、资金归零、补给归零且不给恢复入口。后果可以严重，但必须有优先级和上限。

## 10. 反软锁矩阵

| 极端状态 | 可进行操作 | 不允许发生 |
|---|---|---|
| 三人轻伤、疲劳低 | 可正常出战 | 轻伤被误判重伤 |
| 两人重伤、一人健康 | 选择健康+一名轻伤/恢复 | 用主角补位 |
| 四人重伤 | 桌面恢复、读档、等待恢复 | 必须战斗才能恢复 |
| 四人疲劳 ≥80 | 桌面恢复、下一周期留守 | 只能接战斗任务 |
| 资金 0 | 接恢复/补救、桌面恢复 | 直接 game over |
| 补给 0 | 安全路线、撤退、恢复 | 自动凭空增加补给 |
| 士气 0 | 执行关键行动但效率较低 | 拒绝护送/搬证物导致主线死路 |
| NPC 支援耗尽 | 基础路线、部分成功、撤退 | 主线不可开始 |

## 12. 制作任务

1. 创建四名冒险者配置和 4 选 3 队伍界面。
2. 接入状态服务、出战快照、留守快照和周期关闭恢复。
3. 接入伤病/疲劳/压力/士气显示、原因日志和软修正上限。
4. 实现桌面恢复和全员不适的无软锁路径。
5. 实现三档难度、锁定时机和相同基础奖励。
6. 编写短回响并确认没有隐藏好感/关系字段。
7. 执行 TC-D05-01 至 TC-D05-16；未执行不得标记通过。
