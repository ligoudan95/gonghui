## 1. 数值使用说明

本文件给出可直接灰盒实现的单次 DEMO 基线。它们是**首轮测试参数**，不是已经平衡的最终值。改动时保留净收益计算、漏洞测试和前后版本记录。

### 1.1 初始账本

| 字段 | 初值 | 上限/规则 |
|---|---:|---|
| 资金 `funds` | 100 | 可用资金不允许负值；欠费转债务 |
| 补给 `supply` | 5 | 携带/仓储上限 8 |
| 事实情报 `facts` | 0 个 | 集合去重；不消耗 |
| 声望 `reputation` | 0 | DEMO 只做少量正负反馈，不兑换货币 |
| 联络位 `contact_slots` | 1 | 每周期最多准备 1 名 NPC |
| 准备动作 `prep_actions` | 2 | 周期关闭后恢复 2 |
| 维护费 `maintenance` | 10/周期 | 关闭周期时只扣一次 |
| 出发基础成本 | 12 | 出发事务提交后不退 |
| 债务上限 | 40 | 超过进入重整，不阻断恢复入口 |

资金、补给和债务使用正式版 [`zhengshi/03`](../zhengshi/03-资源经济、维护与破产保护策划案.md) 的 committed/reserved/debt 三栏；facts 使用正式版 [`zhengshi/06`](../zhengshi/06-地图节点、信息层级与回访规则策划案.md) 的稳定 ID 集合。

## 3. 两条准备委托

### 3.1 旧矿道测绘

- 接受条件：开场后可见。
- 目标：调查一处外围路线，不进入主战棋。
- 成本：消耗 1 补给、1 准备动作。
- 结果：获得固定 `fact_waterway_exit`（DEMO-04 §4 事实表的来源 A），资金 +18。
- 失败/取消：已消耗的补给按任务状态处理，不发收益；可以在下一周期生成转化为低收益的补救调查。
- 重复规则：同一周期不可重复；再次刷新时任务版本必须有新内容或新 `reward_id`，不能重发旧 fact 和旧资金。

### 3.2 矿工家属访谈

- 接受条件：开场后可见。
- 目标：获得失踪者和目标物线索。
- 成本：1 准备动作；无资金/补给成本。
- 结果：获得固定 `fact_missing_worker_last_seen`（DEMO-04 §4 事实表的来源 B），资金 +10。
- 失败/取消：不发资金；若已完成访谈，不能重复领取。
- 重复规则：每个周期最多一个实例；本任务不是无限赚钱来源，周期关闭才可能出现下一次有内容的访谈变体。

### 3.3 净账例

标准低风险准备路径（准备动作只有 2 个，本例选择两条准备委托）：

```text
初始 100 资金、5 补给、准备动作 2
测绘委托（动作 1）：+18、-1 补给 -> 118，补给 4
家属访谈（动作 2）：+10          -> 128
出发 -12                         -> 116
水道路线/战棋消耗 -2 补给         -> 116，补给 2
完全成功 +65                     -> 181
周期维护 -10                     -> 171
```

准备动作上限为 2（见 §1.1），因此“购买情报（-15、1 动作）、补给采购（-8/份、1 动作）、推进 NPC 首阶段（1 动作）”与本例的两条委托相互竞争，选择它们会相应减少净资金。这条路径不是目标最优值，只是检验账本的示例。若测试发现玩家能在不出发、不关周期的情况下重复取得 +18/+10，判定为 P0 经济漏洞。

## 4. 结果净收益基线

| 结果 | 资金净额（不含玩家额外采购） | 补给 | 主要代价 | 后续 |
|---|---:|---:|---|---|
| 完全成功 | +65 | +1 可选 | 轻度疲劳/风险反馈 | 新钩子，证据和救援均保留 |
| 代价成功 | +45 | 0 | 轻/重伤、丢证据或声望变化之一 | 支援/补救反馈 |
| 部分成功 | +25 | 0 | 一个主目标转后续，敌方警戒提高 | 新补救任务 |
| 撤退 | 0 | 不返还已耗 | 保留 facts，放弃物证或目标推进 | 敌方取得先机 |
| 失败继续 | 0 或 +8 | 不返还已耗 | 债务/声望/伤病/追责 | 保证下一步恢复或补救 |

失败补偿的目的仅是让玩家能继续，不应让“主动失败”比完成准备和成功回收更赚钱。`+8` 仅在任务明确配置了救援/转介服务时使用，并同时产生周期或债务代价。

## 5. 破产和最低恢复

### 5.1 进入条件

周期维护需要 10 资金而可用资金不足时：

- 先支付可用余额。
- 未支付部分写入 `debt`，不把 funds 变成负数。
- 显示债务、声望或政治后果（资金压力是 `debt > 0` 的派生表现，不引入正式版的 `FINANCIAL_PRESSURE` 状态）。
- 不显示 game over。

### 5.2 DEMO 桌面恢复服务

当资金为 0、补给为 0、或合法出战人数不足 3 人时，主界面开放“桌面恢复”：

- 不要求现金、特殊 NPC 或健康成员。
- 不发现金、补给、经验、物品或可出售资源。
- 提交一次周期关闭，使用周期机会和债务/声望提示作为代价。
- 为至少一名成员减少疲劳或推进伤病恢复，或生成不需要战斗的补救入口。
- 同一周期只能使用一次；使用后不能在菜单中再次点击获得第二次恢复。
- 若债务达到 40，上限不会让系统硬锁；恢复仍可用，但会转为“重整/公开求助”路径，下一次任务的声望或期限代价更明显。

恢复服务不是刷钱按钮：它的账本净变化不增加可支配资产，且必然推进一个周期。

## 6. 时间和远征预算

### 6.1 远征 local_tick 基线

| 行动 | local_tick | 补给 | 说明 |
|---|---:|---:|---|
| 从入口到普通节点 | +1 | 0 | 路线配置另有风险 |
| 入口到危险捷径 | +1 | -1 | 可能提高暴露 |
| 普通调查 | +1 | 0 | 关键调查节点配置 |
| 营地 | +2 | -1 | 只影响远征内部恢复/风险 |
| 进入主战棋 | +1 | 0 | 建立战斗快照 |
| 主战棋基础消耗 | +1 | -1 | 结果提交时一次 |
| 撤退 | +1 | 0 | 生成撤退结果 |

`local_tick` 只影响远征内部提示、暴露和路线压力，不直接让主线跨周期过期。

### 6.2 世界周期

DEMO 的标准体验是一个完整行动周期（一次主线远征）；失败、恢复与补救允许在同一运行内继续后续周期（`CYCLE_CLOSED -> PREPARING`，见 DEMO-01 §1，上限 3 个周期），但 DEMO 不验证多周期经济曲线：

- 准备动作不直接推进 world cycle。
- 出发远征完成、接受结果、处理回响后才能关闭周期。
- 关闭时扣维护、处理恢复和失败后果，`world_cycle +1` 一次。
- 休整/桌面恢复也会关闭周期，不能用“什么都不做”无限暂停维护。

### 6.3 时长预算

- 开场+教程：5–8 分钟。
- 准备：10–12 分钟。
- NPC 接触：5–7 分钟。
- 探索：14–18 分钟。
- 战棋：15–20 分钟。
- 结果回响：8–10 分钟。

若测试中准备委托和 NPC 文本把首玩推过 75 分钟，优先删重复文本和节点，不删除失败结果或基础路线。

## 7. 任务刷新和反刷规则

- 准备委托实例在 `CYCLE_CLOSED` 刷新一次；打开菜单、取消接单、读日志不刷新。
- 每个任务实例有稳定 `quest_instance_id` 和 `reward_id`。
- 未完成任务不会因为离开界面回到 `VISIBLE` 并重新生成奖励。
- 领取结果后重复请求返回已领取，不重复资金和 facts。
- 购买情报的事实 ID 已存在时不收重复费用；可显示“已掌握”并不生成现金回退。
- 通过读取旧档重新做任务属于新的时间线，不把两条线的收益合并。

## 8. 失败路径账例

```text
周期 1：
初始 100 资金、5 补给
不购买情报，直接出发 -12                 -> 88
两次移动 -1 补给、战棋基础消耗 -1 补给    -> 88，补给 3
战棋失败，接受结果：报酬净额 0（资金不变）、
  重伤 1 名、声望 -1                      -> 88，补给 3
周期关闭：维护 -10                        -> 78；重伤留守 2→1

周期 2（补救远征）：
出发 -12                                  -> 66
再次失败：另一名重伤、报酬净额 0           -> 66
周期关闭：维护 -10                        -> 56；伤病各降一档
```

“报酬净额 0”指失败不发报酬，不是清空现有资金；出发成本与消耗照常扣减。债务与桌面恢复是跨周期边缘状态：连续失败且无收入时，每周期维护 -10 与出发 -12 会逐步耗尽资金（进入 §5.1 债务）；连续出战使疲劳/伤病叠加则可能令可出战人数不足 3（进入 §5.2）。它们是安全网；TC-D02-07 允许用预设前置存档直接构造“资金 0/全员不适”来验证入口存在且不 game over，不要求一次自然游玩走完整个边缘态。该路径验证的是“失败前进”，不是鼓励失败。若失败后可自由转卖恢复奖励并立即超过 100 资金，修复恢复收益或增加债务/机会成本。
