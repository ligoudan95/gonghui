## 二、动作集技术设计

### 2.1 资源 id 体系扩展

- 动作件 id = `<sprite_id>_<action>`，action ∈ {idle, move, melee_attack, cast_ranged, hit, downed}；9 单位×6 动作=54 件（美术总量约 80→约 125 件）
- 每件一张竖条 PNG：宽 128、高=帧数×128，帧数由图高自动推导
- 循环性按动作语义固定：idle/move=循环、melee_attack/cast_ranged/hit/downed=单次；downed 播完锁末帧（尸体常驻至战斗结束）
- AssetRegistry 结构零改（仍 mapping: Dictionary），新增 54 键，原 9 个单图键删除（静态图退役，gen_unit_sprites 旧工具同步退役）
- naming_registry 登记 160→214 条
- 无新数据表；V-M6 组校验登记案 16 §2.6

### 2.2 帧动画载体：竖条 PNG + AtlasTexture + 代码帧推进

弃用 AnimatedSprite2D+SpriteFrames，理由：①SpriteFrames .tres 内嵌 PNG 路径与 AssetRegistry 形成路径双源，绕开铁律②并破坏 V-R4-asset-reverse 护栏 ②UnitBadge 现有 TextureRect 最小改造 ③帧推进逻辑独立纯函数 headless 可测 ④替换粒度=动作级（单动作重产不影响其余 5 动作）。

#### UnitAnimState 设计

- 枚举 Action { IDLE, MOVE, MELEE_ATTACK, CAST_RANGED, HIT, DOWNED }；LOOP_ACTIONS=[IDLE, MOVE]
- 变量：current/frame_index/frame_count/_accum（全量类型标注）
- request(action)->bool：优先级 DOWNED 吸收一切（已倒地恒拒绝）> HIT > MELEE_ATTACK/CAST_RANGED > MOVE > IDLE；同动作重请求幂等返 false
- advance(delta, fps)：循环回绕；单次到末帧停（DOWNED 停末帧；HIT/攻击类停末帧等 finish_check）
- is_once_finished()/is_downed_locked()：判定口
- 调用链：battle_screen 分派→battle_board.play_badge_action→badge.anim.play_action（badge 内 _Process 驱动 advance 并按 frame_index 重设 AtlasTexture.region）

#### SkillDef.attack_pose（技能级动作路由）

AttackPose { NONE, MELEE, CAST }——技能级而非单位级：精英=穷追（近战）+怒吼（AURA 施放）双形态、游侠 set_trap 与射击姿态不同。

23 条回填：

- MELEE=skl_atk_warrior/skl_atk_rogue/skl_atk_enemy_common/skl_warrior_power_strike/skl_rogue_backstab/skl_enemy_plague_bite/skl_enemy_dirty_trick/skl_enemy_relentless
- CAST=skl_atk_mage/skl_atk_priest/skl_atk_arcanist/skl_atk_ranger（弓姿泛用）/skl_mage_fireball/skl_mage_frost_chain/skl_priest_heal/skl_priest_smite/skl_ranger_piercing_arrow/skl_ranger_set_trap/skl_arcanist_curse/skl_arcanist_bewitch/skl_enemy_intimidating_roar
- NONE=skl_warrior_shield_wall/skl_rogue_sprint（纯自身增益不播攻击）

#### cfg_main 演出参数组（7 字段，均占位·试玩校准）

ui_anim_idle_fps 6.0 / ui_anim_move_fps 10.0 / ui_anim_attack_fps 8.0 / ui_anim_hit_fps 8.0 / ui_anim_downed_fps 6.0 / ui_battle_move_step_seconds 0.15（移动 tween 单步，测试注 0 先例）/ ui_hit_flash_seconds 0.25

### 2.4 动作状态机接线（battle_screen 十信号→动作分派）

- battle_started→全员 IDLE；turn_started(u)→u IDLE
- unit_moved→u MOVE+badge 位置 tween（cfg 时长×步数钳制），tween 完→IDLE
- skill_executed(caster,result)：caster 按 SkillDef.attack_pose→MELEE_ATTACK/CAST_RANGED（NONE 不动；flip 按双方 x）；result.hit==false→目标不播 hit+飘 MISS；damage>0 且 hit→目标 HIT+play_hit_flash()
- status_changed→不接动作（控制状态=图标+modulate 程序化）
- round_settled(_,dot_damage)→逐承伤者 HIT（跳伤致死由 unit_downed 覆盖为 DOWNED——优先级自然处理）
- trap_triggered→u HIT
- unit_downed→DOWNED（末帧锁定；隐藏血条/资源条/高亮环；灰度维持）
- battle_ended→不动（尸体常驻至场景销毁）
- MISS 飘字：battle_board show_float_text 泛化；文案入 UI_TEXTS（miss_text="闪避"）
- 三致倒路径（攻击/DOT/陷阱）统一经 BattleController unit_downed 信号——动作层只消费该信号天然统一，测试覆盖三路径断言 DOWNED

### 2.5 占位过渡：程序化占位动作帧先行

tools/gen_unit_anim_frames.gd（headless 幂等，registry 仅重建 spr_* 键）：以现有 9 张静态图几何变换生成 6 动作竖条——

- idle 2 帧（上下 1px 浮动）
- move 4 帧（水平±2px 摆动+纵向起伏）
- melee_attack 3 帧（前倾 4px+水平压缩 8%）
- cast_ranged 3 帧（后仰回正+亮度脉冲）
- hit 2 帧（白化 60%+位移 2px）
- downed 3 帧（旋转 15°→45°→90° 压扁躺平，末帧=尸态）

产出 54 张占位 PNG+registry 同步——链路即刻全量可跑可测，正式件到位按动作件 id 原位替换零改表；校验在占位态即全绿。

- **D1 素材产出方式**：A 推荐=团队规格书+工具、用户执行生图购买入库；B=团队直接产出素材（需工具链授权，125 件迭代沟通成本高）
